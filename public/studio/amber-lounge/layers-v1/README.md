# 暖琥珀分层运行候选

2026-10-16。此目录保存三张生成 PNG 的同源运行副本；它们与[生成母版](../../../../assets-source/amber-lounge/layers-v1/README.md)逐字节相同，没有数值脚本修图、缩放、重采样、重新编码或像素补绘。

| 文件            | 原生尺寸与通道  | 用途                                              |
| --------------- | --------------- | ------------------------------------------------- |
| clean-room.png  | 1774×887，RGB   | 移除家具后的 LDR 全景背景，填补分层视差暴露的区域 |
| chair-table.png | 1536×1024，RGBA | 椅子与边桌组成的固定图像卡片                      |
| table-lamp.png  | 1280×1229，RGBA | 独立台灯固定图像卡片                              |

`clean-room.png` 中原先被家具遮挡的墙面、地面及相关细节由生成工具推断补全，不是实测隐藏表面、相机标定结果或完整三维房间。三图均是 sRGB LDR 颜色图，不是实测 HDR、深度、法线或完整 PBR 数据。

椅桌和台灯 PNG 使用真实 alpha 透明通道，背景透明并保留边缘过渡；透明不是绘制在图里的棋盘格。两者是具有固定透视和烘焙明暗的平面卡片。斜视会暴露厚度不足，背面观看可能暴露镜像或缺少背面信息，不能替代可以任意环绕的完整 3D 家具。台灯图中的亮度及物体上的光照已经烘焙，另加场景灯光也不会将这些像素变成实测照明数据。

[manifest.json](manifest.json) 记录运行文件的字节数、SHA-256、尺寸、颜色空间和源路径；[generation.json](../../../../assets-source/amber-lounge/layers-v1/generation.json) 保存生成日期、工具、输入全景及三次生成的完整提示词。输入来自[已有暖琥珀全景](../v1/README.md)，其更早来源见[母版记录](../../../../assets-source/amber-lounge/v1/README.md)。原件保持不可变；需要修订时另建候选和清单，不能覆盖原件后沿用旧摘要。

这些图片由内置 image_gen 为本项目生成，不登记为第三方摄影素材或 CC0 资产。此包属于 `experimental-inferred-layers` 候选，清单与来源记录不代表任意角度画质或真实三维重建已通过验收。
