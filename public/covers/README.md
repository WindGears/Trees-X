# 商品封面

六个导入商品的 JPG 原样复制自用户提供的 `heritage-museum/heritage-web/public/covers`，为该项目对相应 CC0 模型的渲染封面。对应作者/模型来源见 `../models/collection/README.md`。

`form-01.jpg` 为本项目原创 GLB 的浏览器渲染截图，720×400，使用原生 Canvas 截图生成；拍摄时隐藏页面文字、热点和控制台，使用浅灰背景。图片没有生成式补绘，不作为真实商品照片。

封面用于目录。目录不开设额外 renderer，点击后由现有唯一 TresCanvas 加载相应 GLB。
