# 汽车冷白实体摄影棚：节点一

日期：2026-10-22。基线代码 `497b33c`，候选使用 `carShowroom=cold-studio`。本节点不实现车身世界空间光追，不替换普通入口；下一节点必须独立比较。

## 实现与可复现入口

[冷白棚候选](http://127.0.0.1:5181/?product=reventon&renderPipeline=realtime&indirectLighting=ddgi&assetLoading=streaming&reventonAsset=runtime-v2&carQuality=studio&carKeyShadow=1&carShowroom=cold-studio)；删去 `carShowroom` 即同资源旧棚对照。仅准确核验的汽车包、真实 WebGPU、studio 材质和实际相机启用；自定义包、WebGL、其他商品不替换。

`rendering/carShowroom` 是实体建筑、局部探针、材质绑定与避让的独立资源所有者。真实地面、四面弧形墙脚、墙体、顶棚及两个带厚度灯箱全部由配置构建，不请求房间图片。灯板与面灯共用位置、尺寸、颜色；车漆参数、4K贴图、模型几何、轴心和机构保持。

配置 revision 2 是唯一一轮集中美术修正：提高墙地可见性，扩大侧后方软箱，地面改为克制的固定数值微表面与宽柔高光。它是美术材质，不是扫描石材。UI布局保持，只修正暗背景文字对比。

## 信号与能量组织

- 镜面：同一静态房间六面1024² RGBA16F捕获，转换4096×2048线性Float32等距图，保留1024级PMREM输入；基础和清漆采样均有世界空间盒投影。SSR未命中继续原生环境，未设置单独 `material.envMap`。
- 漫反射：另作一次六面256²低频捕获，仅将捕获房间灯板置黑，墙地继续受同一面光照亮。1024×512输出用于原生粗糙度1的环境漫反射和DDGI SH9；不是完整镜面输入的降分辨率。
- 两次捕获共12次面绘制，每个房间实例仅准备一次；相机、开门和分离不重拍。完整环境与间接环境各有独立PMREM所有者；旧EXR保留作回退，不完整相加。
- 房间专用RectAreaLight在renderer局部注册；保留原生LTC漫反射、主软箱可见性，镜面及清漆直射项流入局部弃用累加器，避免与灯板IBL重复。Basic／深度／阴影等非Physical编译沿用原生处理。
- 墙地进入既有DDGI借用代理，灯板不再作为发光代理。体积仍覆盖汽车运动包络。Speedball的SH9、面灯中心点近似与既有材质限制保持，不能称为完整路径追踪。

## 生命周期与观察

同一个Tres Canvas、renderer和绘制时钟。房间材质/几何/数值贴图、探针目标、投影hook及原车loader各有唯一所有者；取消／迟到／基础准备期间卸载都有测试。捕获在停止绘制的既有preparation lease内完成，renderer完整状态先恢复再等待一次性读回，不作逐帧CPU读回。

原相机范围保持。主相机前的建筑通过240ms暂停式GSAP补间淡出，减弱动态直接切换；捕获房间是独立同配置实例，DDGI借用未淡出的原材质。避让按静态建筑包围盒和汽车运动包络进行保守检测，可能比准确遮挡略早；不改变相机自由度。淡出墙体不写入不透明G-buffer，地面保持不透明、SSR可用；建筑反射由完整探针提供。

完整镜面CPU图134,217,728字节、低频CPU图8,388,608字节；镜面临时cube颜色50,331,648字节、转换颜色134,217,728字节，捕获后释放。以上不含深度、驱动对齐、PMREM输出/工作目标及其他场景资源，不能当作实测显存。

## 实机发现与修正

第一次诊断发现灯节点错误拒绝BasicLightingModel，灯板程序编译失败而捕获最大值仅0.030。已修正并新增主灯／条灯回归；再次真实GPU诊断无控制台错误，完整HDR最大值恢复8.5。失败截图和诊断保留在忽略的 `artifacts/car-showroom/`，不把最初暗场当作通过。

第一轮真实Edge无头生产对照：旧棚／初版新棚各11个固定取景，包含整车、侧后、顶部、车漆、门板、车轮、开门、座舱、分离与房间外观察；两组操作、实际身份、唯一Canvas、DDGI、自阴影、双SSR和静态捕获检查通过。无渲染／请求错误。单次首可操作20.013／20.770秒，完整增强观测26.161／27.222秒；是该批单次观测，不代表分布或提速。

集中美术修正后的 revision 2：11取景及绕行／双门／分离短操作通过，无渲染或网络错误。该批单次首可操作22.388秒，完整增强28.781秒。真实管理员预览、GPUDevice.destroy恢复、暂停动作与镜头检查点、取景回填后重新预览共4项通过；数据库原文摘要前后相同，离开预览Canvas归零。没有把预览写回数据库。

独立运行测量开启GPU timestamp，关闭录屏，真实1440×1000：单次首可操作26.903秒、完整增强33.584秒。不同批次存在缓存、机器和诊断开销差异，不据单次数字推断加载提速／回退。

## 窗口缩放修补与最终短测

五尺寸首次回归发现实际GPU报错：窗口缩小时beauty引用已销毁的surface depth和阴影过滤纹理。已补两层保护：共享scene附件及嵌套阴影输出在任何依赖绘制前统一调整尺寸并 `initRenderTarget`；盒投影材质同时登记真实 `envNode`，让r185 NodeMaterialObserver识别节点输入，为复用同一材质的静态部件刷新动态绑定。只覆盖实例，恢复时还原原envNode和方法，不改原型、不重建Canvas或整套渲染图。

修补后真实WebGPU依次切换1280×720、1440×1000、1920×1080、390×844和320×740通过，保持原Canvas、renderer及环境身份，没有重拍；减弱动态基础检查通过。桌面标题和说明已改为浅灰白，五尺寸均校验真实计算样式，无横向溢出。320px为基础兼容，建筑边缘与商品占比仍以桌面为主要画质验收范围。

由于节点登记会影响每部件的绑定更新，重新完成一次最终三段30秒短测，前一表保留为修补前记录。最终首可操作23.644秒、完整增强35.743秒；不是多次加载分布。

## 工具与验收口径

```bash
node scripts/reventon-showroom-check.mjs --mode visual
node scripts/reventon-showroom-check.mjs --mode performance --gpu 1
node scripts/reventon-key-shadow-flow-check.mjs --showroom 1 --device 1 --output artifacts/car-showroom/flow
node scripts/reventon-showroom-layout-check.mjs
```

全部强制无头，不置前、不改变用户焦点。只看启动与短段运行，不执行重载／长测。JS完整场景提交、GPU timestamp和显示器实际呈现分开；前两者不能替代30FPS显示验收。管理脚本阻止数据库写操作，仅预览与取景回填。

本批893项Vitest通过，生产前后端构建通过。`npm run check` 的类型与ESLint通过后，被用户未跟踪的 `PERFORMANCE_OPTIMIZATION.md` 格式阻断；该文件保持原样，不称check全通过。最终画质由用户实机确认后再安排默认切换。

## 来源与边界

新房间和数值贴图为本项目原创代码，未增加外部房间资产。基于[Three CubeCamera](https://threejs.org/docs/pages/CubeCamera.html)、[EnvironmentNode](https://threejs.org/docs/pages/EnvironmentNode.html)及r185 PMREM／Physical实现；面光源限制见[RectAreaLight](https://threejs.org/docs/pages/RectAreaLight.html)。节点一是局部IBL与SSR组合，不是新接通的RTX硬件光追。汽车原资产的公开条件不因新房间改变。
