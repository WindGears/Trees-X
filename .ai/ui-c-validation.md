# 方案 C 访客界面验收

2026-10-11。用户已选择极简、浅银灰淡灰绿毛玻璃的方案 C，并要求操作与动效流畅。本记录只对应本轮访客 UI；E1 的长时运行与资源测量仍见 demo-validation.md，不能当作本轮新增测量。

## 实现范围

- 保留一个真实 Three.js 舞台、同一 Canvas/renderer 和三件正式 GLB。打字机仍为首页，快速栏使用三件真实商品封面及公开 API，完整目录检索独立。
- 左侧浮动快速商品栏，右侧单活动面板，底部探索导航与紧凑视角/缩放工具；管理端、管理预览和 legacy 不重做。
- GSAP 管理进入 0.32 秒、退出 0.18 秒的面板过渡，导航选中块 0.3 秒；同一面板切换工具时立即替换内容，执行 0.22 秒进入补间，不等待旧内容离场。旧补间可取消，退出面板立即 inert，关闭面板恢复焦点。
- 面板开关只以 0.32 秒横向调整相机投影构图，缩放适配只随视口尺寸，不因开面板缩小商品；保留实际相机位置/目标、配色、结构和部件状态。缩放、旋转、聚焦、导览及动作接管沿用原规则。
- 引线标签新增 Root 范围的动态障碍收集，覆盖快速栏/面板/顶栏；MutationObserver 与 ResizeObserver 跟随挂载和尺寸，卸载断开。
- 背景与地面采用浅灰；没有新增展厅墙窗、HDR、纹理或改变正式模型几何与材质。概念图不是当前模型精度或照片级实机效果证据。
- 局部背景模糊有实色回退；减弱动态直接到目标，页面隐藏和卸载沿用场景停钟与唯一释放方。

- 初轮批量审查三件桌面、移动端与目录截图。修正面板打开时商品缩小：缩放只随视口计算，面板只横向移动构图；补充顶栏局部浅色玻璃底，保证黑色近景后方的文字对比，并调整快速栏中文换行与介绍宽度。

- 集中修正后一轮确认首屏、面板、320px、钢琴、汽车动作及目录截图，结束本轮视觉调整，不继续追加视觉方案。

## 复现命令

`npm run check`、`npm run build`、`npm run demo:prepare`、`npm run demo:start`。

开发入口通过环境变量 `CHECK_URL=http://127.0.0.1:5183` 分别运行 `node scripts/workbench-ui-flow-check.mjs` 与 `node scripts/callout-check.mjs`。生产入口使用 `CHECK_URL=http://127.0.0.1:5181` 运行 `node scripts/demo-production-check.mjs`。`UI_FLOW_OUTPUT`、`CALLOUT_CHECK_OUTPUT` 与 `DEMO_PRODUCTION_OUTPUT` 可指定忽略的证据目录。开发测试中的场景桥接仅用于验证真实相机/资源身份；生产检查不依赖 Vue 内部桥接。

## 范围与限制

本轮未再执行 20 分钟持续演示、30 次正式资源循环或 GPU 性能测量，也没有新增真人用户/手势测试；已有记录分别保留在 E1 与对应验收文档。UI 自动化通过不能替代本人体验反馈。完整展厅环境和更高质量模型制作属于后续明确选择的阶段。
