# 摄影棚几何边缘抗锯齿候选（2026-10-27）

## 实现与范围

已核验汽车 WebGPU studio 增加显式 `carAntialias=msaa`。beauty 的
HDR 颜色、RGBA8 透过率附件及深度采用 4× MSAA；surface G-buffer 继续单采样，避免平均
不同表面的法线、运动与深度。最终 SMAA 保留。默认入口仍为原采样方式。

准备阶段与真实绘制使用相同 sample count；候选进入 signal identity，
切换时由既有 owner 重建并释放信号图，复用唯一 renderer 与时钟。
诊断读取实际 renderTarget.samples，不把请求值当作实际目标状态。
运行资产、相机、灯光与材质不变。多采样增加目标存储及带宽成本；
本批未取得独立 GPU 显存字节审计，不以纹理数量声称成本相同。

## 定位与真实检查

- `artifacts/car-showroom/edge-isolation`：关闭 SSR/GI 后，墙缝与轮廓的
  点状边缘仍存在；near 从原值临时调至 0.5 也未消除。诊断不修改商品配置。
- `edge-msaa`：同灯光、同取景开启 4× beauty，几何边缘连续性改善。
  这不代表反射随机噪声、透明贴片或全部细边问题均已解决。
- `msaa-r11`：全景、侧面、背面、开门、分离、面板与目录共七个取景；
  实际 GPU 检查通过，beauty=4、surface=0，无页面/GPU错误，唯一 Canvas。
- 147 个测试文件、934 项测试通过，生产构建通过。类型与 ESLint 通过；
  完整 check 的格式步骤仅被已有用户文件 PERFORMANCE_OPTIMIZATION.md
  阻断，未改该文件。

## 短测与边界

1440×1000，后台无头 Edge，保持原输出。只测一次启动与三段各30秒操作。
可操作 31.216 秒，增强就绪 49.792 秒；单轮不能作为冷/热加载统计。

| 操作 | 原 r11 提交间隔中位/P95 | MSAA 中位/P95  | MSAA 完整提交次数/秒 |
| ---- | ----------------------- | -------------- | -------------------- |
| 绕行 | 19.3 / 24.0 ms          | 19.2 / 24.8 ms | 50.29                |
| 开门 | 23.3 / 30.9 ms          | 23.8 / 32.2 ms | 39.03                |
| 分离 | 23.0 / 30.3 ms          | 23.4 / 32.1 ms | 39.45                |

数据来自 balanced-r11-performance 与 msaa-r11-performance/report.json。
这是 JS 完整场景提交间隔，非显示器呈现帧率、非 GPU 单帧耗时；
两轮差异包含运行波动，不能据此宣称提速。实际呈现30帧目标仍待验收。

摄影棚整体仍未视觉通过：轮毂和座舱暗部、默认构图及部分反射残差继续修整。
本批不进入车身世界空间反射节点，也不替换普通默认入口。
