# 工作台标签尺寸测量

浮动工作台原先每次投影提交都会临时显示隐藏的标签按钮并读取宽高。现在仅在标签内容、选中状态、尺寸和字体变化时重新测量。隐藏标签成批临时显示、读取和恢复。每帧仍采集浮动面板的位置，确保面板平移期间的避让使用当前边界。

生产构建以 1440×1000 在同一个无头 Edge 会话用 NVIDIA WebGPU 依次执行参考、缓存、缓存、参考四组，每组包括各 8 秒的绕行、开门和分离。参考组恢复原逐帧读取路径，其余代码与缓存组一致。

| 指标                           | 逐帧测量         | 缓存尺寸     |
| ------------------------------ | ---------------- | ------------ |
| 每组稳定绕行的标签尺寸读取     | 12,620–12,660 次 | 0 次         |
| 每组稳定绕行的尺寸读取累计耗时 | 473–492 ms       | 0 ms         |
| 绕行 JS 提交中位               | 12.2–12.3 ms     | 11.7–11.8 ms |
| 绕行 JS 提交 P95               | 15.9–16.2 ms     | 15.5–15.9 ms |
| 开门 JS 提交 P95               | 22.6–22.9 ms     | 22.4 ms      |
| 分离 JS 提交 P95               | 22.8–22.9 ms     | 22.7–22.8 ms |

另有四次独立冷启动的对照也消除了稳态读取，但动作段提交 P95 波动更大，较慢样本没有在同会话对照中重现。绕行的输入数会随实际帧间隔变化。以上是后台提交和 DOM 读取观测，实际屏幕呈现仍待验收。

单测覆盖隐藏状态恢复、持续采集移动面板、内容与尺寸变化、字体和监听释放。三件展品的生产标签回归覆盖淡入淡出、相机跟随、选中优先、避让、桌面和移动端尺寸、WebGL 恢复及切换。回归脚本复用现有生产版场景探针。原始结果位于 `artifacts/r18-startup-deep/callout-measure-*`。
