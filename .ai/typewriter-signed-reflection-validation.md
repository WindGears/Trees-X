# 打字机有符号反射修正验证

2026-10-14；1440×1000、实际发布 GLB、572 个语义部件、2257 个实例。仅更新打字机实时实验入口；默认 WebGL、源资产及钢琴／汽车保持。节点一整体画质仍未通过，不进入 UV／材质 v2、DDGI 或默认切换。

## 实现与边界

- 原先过滤“SSR 命中／原生环境替换”后再减原生环境，邻域和时域权重可能留下未命中残差。现在仅过滤有符号修正 `D`：受支持命中为 `SSR × AOcoat − nativeSingle`，未命中或未支持为精确零；原生 Physical beauty 本身不参与该过滤，最终增加过滤后的修正。
- 空间过滤固定八个采样，深度、法线、粗糙度和稳定的原生环境亮度参与引导；每个邻域样本的支持判断同时控制分子及分母。不使用修正信号自身的逆亮度权重，不把有限负值截为零。
- 时域以四采样运动重投影结合前后深度、世界法线和粗糙度判断，历史限制在当前受支持邻域的有符号最小／最大值内，历史计数最多 16。全零邻域可截去旧非零历史。
- 相机、深度、法线与信号历史只在协调器最终绘制提交返回且无已报告错误后共同提交；失败、取消和变更重建不提交。这是绘制提交口径，不保证 GPU 异步校验已经完成，也不等于屏幕呈现计时。历史目标及克隆引导纹理由局部所有者释放，不释放上游 MRT、loader 几何或材质。
- 几何权重和重投影换算参考 Three r185 的 MIT 实现：[RecurrentDenoiseNode](https://github.com/mrdoob/three.js/blob/r185/examples/jsm/tsl/display/RecurrentDenoiseNode.js)、[TemporalReprojectNode](https://github.com/mrdoob/three.js/blob/r185/examples/jsm/tsl/display/TemporalReprojectNode.js)。本实现没有完整镜面命中点重投影、自适应核或 Karis 权重，不能称为原生两节点完整等价或新提出的降噪算法。

## 真实 GPU 证据

忽略目录 `artifacts/typewriter-quality-node1/signed-probe/` 保存六次 GPU 捕获、原始二进制、类型／格式／行跨度及摘要。同一成功完整帧复制实际五个目标：SSR、native、rawDelta、spatialDelta、filteredDelta；没有第二个绘制时钟或生产逐帧 CPU 回读。

| 信号          | Alpha 的实际含义                          |
| ------------- | ----------------------------------------- |
| SSR／rawDelta | 原始 SSR 射线长度；10000 为环境未命中哨兵 |
| native        | 支持的原生单次散射项对应 AO／清漆透过权重 |
| spatialDelta  | 当前像素支持标记                          |
| filteredDelta | 有效历史计数；不能据此判断原始 SSR 命中   |

旧统计助手继续使用 CPU 重建的 `native + filteredDelta` 作为其 replacement 输入。它不是读回的 GPU replacement 目标；真实有符号契约另对五个实际目标执行检查。PNG 为读回之后的相同固定姿态帧，不冒充该 GPU 提交的截图。

| 检查                                 | 本批实际结果                                                                |
| ------------------------------------ | --------------------------------------------------------------------------- |
| 六次有符号契约捕获                   | 全部通过；非有限像素 0                                                      |
| 自然整机，首次捕获                   | 186136 个支持命中；533890 个支持未命中；719974 个未支持像素                 |
| 自然整机，首次 filteredDelta         | 最小值 −0.2098388671875；最大值 0.284912109375；负修正实际保留              |
| 自然整机 rawDelta 契约最大误差       | 0.000701904296875；检查允许 HalfFloat 表示误差                              |
| 保留预热历史后强制全未命中，两次捕获 | 每次 898237 个支持未命中；raw 契约误差 0，filtered 最小／最大／RMS 均精确 0 |

强制全未命中是明确标记的合成信号诊断，不是画质照片。此前 HalfFloat 版本同类诊断的非零残差已经消除；它不证明自然运动噪声全部消除。自然局部未命中仍可接收受支持命中邻居的修正，不能要求每个局部未命中像素都为零。

signed-probe-final 完成八次五路捕获。保留暖历史后，强制全 miss 首次 arming 帧 812、捕获帧 813，raw／spatial／filtered RGB 严格零；第二次仍为零。随后模拟 RGB 真黑但 ray length=2 的命中：arming 1044、捕获 1045，raw 契约误差 0，filtered 最小 −0.039825439453125、最大 0；第二次 filtered 最小 −0.2481689453125。两种覆盖均在下一成功完整帧捕获，未重建历史，黑色命中没有被错误当作 miss 或被正值 clamp 消除。黑色命中同样是 synthetic signal，仅验证数据契约，不作为访客画质图片。

## 输入对照与画面审查

`signed-comparison/report.json` 的整机、漆面、金属、键帽、0.6 分层和平铺六取景与 HalfFloat 修复后的前一版匹配：资产、原始材质、姿态、身份、灯光、曝光及渲染设置相同；六组相机及投影误差均为 0。每组纹理计数字节仍为 330549649；这是 Three 资源核算，不是物理显存测量。WebGL 与实时入口的环境／补光不同，另组 WebGL 图不冒充同灯光算法消融。

本轮人工截图检查未见重大文字、地台轮廓或新增明显白点退步；整机、漆面、键帽、分层和平铺总体相近。金属点状痕迹及左上开口更明显，尚未建立整体画质提升的结论；契约通过不等于视觉验收通过。
