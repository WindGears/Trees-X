## 交付前仍需留意

1. **本人走查。** 按 [五分钟演示脚本](demo-walkthrough.md) 在实际答辩环境做一次全流程。自动化和 AI 截图检查已经完成，当前没有本人完整走查的反馈。
2. **明确演示入口。** 普通首页仍为 WebGL 与打字机 v1，截图中机身是旧 Kimi 铭牌。要演示 WindGear，使用 [打字机 v2](http://127.0.0.1:5181/?product=typewriter-study&typewriterAsset=v2)。汽车的冷白棚、亮银和细边修正在 README 的 r18 专用入口，普通汽车链接走基础场景。默认切换仍需单独决定。
3. **换机与归档。** Git LFS、数据库备份和本地运行资产分别保管。r18 还需要本机 `public/models/reventon-runtime-v2/` 和 `src/lib/workbench/reventonRuntimeBundle.json`。这两项随本机交付单独保留，Git 仓库只保留制作与登记说明。标准 `demo:doctor` 核验基础三件资产，r18 以专用入口浏览器验收为准。新备份资源清单记录文件信息，文件需另存。
4. **性能表述。** 钢琴较重，基础汽车首次加载较慢。历史计时区分浏览器调度、提交和真实呈现。当前没有足够证据声明实际屏幕帧率达标。答辩建议使用本机预检过的入口。
