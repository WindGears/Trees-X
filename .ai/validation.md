# Phase 1 验证记录

2026-09-14 的手势增量与 Edge 回归见 [gesture-validation.md](./gesture-validation.md)。下文保留 Phase 1 当时的历史验收记录；当前浏览器脚本已切换为 Edge。

## 资产

FORM / 01 原创 GLB：524,532 bytes，13,432 三角形，26 个图元，无外部贴图。`npm run model:check` 在 5 MB / 100,000 三角形限制内通过。

## 自动验证

`npm run check` 包括 TypeScript strict、ESLint、Prettier、Vue 文件 300 行限制、模型预算和 Vitest。

8 项 Vitest 用例覆盖：模型偏移归一化、共享资源唯一释放、实例面数与超预算拒绝、空模型拒绝、真实 GLB 加载与作用域释放、HTTP 错误重试、HTML 伪装 GLB 拒绝、卸载取消与迟到结果。

`npm run test:browser` 覆盖：

- 1440 × 1000 桌面与 390 × 844 移动端，真实单一 Canvas。
- 立体/正面/背面切换、缩放使画布实际像素变化。
- 复位、节能按钮状态、无横向溢出、无页面 JS 错误。
- 模型 404 后成功重试。
- WebGL 上下文丢失后提示、重新挂载并恢复单个 Canvas。
- WebGL 2 不可用时保留产品信息与替代入口。
- 减弱动态与正常动态路径；键盘跳过导航；320px 窄屏无横向溢出。

浏览器脚本默认要求本机 Chrome 与 `http://127.0.0.1:5178` 的运行实例。桌面/手机截图及 JSON 报告存放 `.impeccable/review/`，不进发布产物。

## 已知边界

最终构建已通过；静态预览的生产产物已验证真实 GLB 就绪、单一 Canvas、自托管中文字重加载成功、无页面脚本错误。依赖审计于本次完成时为 0 项已报告漏洞。

独立视觉复核：首轮提出中文展示字体回退平台字体的问题；修复为自托管 Noto Sans SC 标题子集后，原问题被评为 resolved，复核 disposition 为 ship。此结论仅覆盖该修复项，不代表对后续阶段或所有设备的品质保证。
