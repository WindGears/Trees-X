# 汽车写实摄影棚：第一节点

日期：2026-10-21。基线 `f29f75f`。本节点只交付材质／布光和双射线反射候选，主软箱 BVH 自阴影仍是下一节点，尚未实现。普通 WebGL 不切换，最终画质由用户本人判断。

## 入口与范围

- 原候选：`/?product=reventon&renderPipeline=realtime&indirectLighting=ddgi&assetLoading=streaming&reventonAsset=runtime-v2`。
- 新样片：上面入口加 `&carQuality=studio`。
- 单独比较材质／布光：新样片再加 `&carStudioReflections=1`，保留一条 SSR 射线。
- studio 只接受摘要、路径、版本均匹配的原汽车或已登记 runtime-v2，而且实际 renderer 必须是 WebGPU。管理员自定义资源、普通 WebGL、其他商品不应用。

## 实现与边界

`carStudioQuality` 保存独立候选开关和冻结灯光；`carStudioMaterials` 根据原 VPB 语义 ID 与配置中的车身材质名覆盖运行数值，销毁／装配失败恢复。材质、geometry、UV、4K 图片及机构源文件不改。运行材质仍保留原 Physical 清漆／透射；玻璃 specularIntensity 从 0.22 试调到 0.38，不宣称真实汽车测量参数。

主软箱冻结为强度 8.5、5.5×2.6、位置 [-2.2,3.8,-2.4]；条灯强度 4.8、4.6×0.85、位置 [3.3,2.1,1.4]。EXR、曝光、摄影棚背景与取景保持。主软箱本身仍没有动态自阴影，不能把 DDGI 当成其替代。

双射线共用已有表面／beauty 输入，分别拥有原生 SSR 目标，种子偏移为 104729。局部 r185 受检桥接在每帧原生自增前设置序列，只在完整提交成功后推进；取消／失败重用样本。每条射线先分类命中与未命中并计算 signed Δ，然后平均 RGB。距离只从命中射线生成过滤引导，不能用平均原始 RGBA 判命中。保留原空间半径、最多 32 帧的汽车历史及原生未命中环境反射。

新目标、分类钩子和序列由 reflectionRays 唯一释放；源纹理仍借用。适配失败先清理部分双射线，再保留一条基础射线并报告实际状态。完整时钟、Canvas 和 renderer 均不增加。图复用键包含汽车 studio 能力与采样选项，避免同一适配器的自定义汽车继承旧增强。

## 后台启动与运行短测

实际输出 1440×1000，真实汽车／runtime-v2／DDGI，独立 Edge 无头浏览器；不置前、不切焦点、不覆盖 visibility／focus。没有重载或长测。

不开 GPU 查询的视觉批次，每组独立 context 启动仅一次：原版首可操作／增强观测 23.754／24.591 秒，材质版 19.578／20.831 秒，双射线版 19.409／20.685 秒。按原版→材质→双射线串行，缓存与编译热状态有顺序影响；不能宣称启动加速或统计中位数。

## 画质判断与后续

已检查整车和关键近景截图：候选高光与玻璃反射变化明确，文字、轮胎与动作没有发现本轮新增的明显缺失；不能据此宣称用户已认可。车身／细边仍可见残余噪点，座舱缺少主软箱遮挡的问题仍在。完整运动观感、是否采用该材质风格由用户实机判断。

下一节点才单独实现主软箱动态自阴影，保留现有基础画面；本节点不伪造 `carKeyShadow=1` 已有效。取消、错误恢复及所有权由单元／工具测试覆盖，未重新跑完整设备丢失、管理预览浏览器批次或联合长测。
