# 暖夜空间与生成素材分层验证

2026-10-16。本轮是打字机显式实验，不替换已验收默认入口。用户新增“多生几个素材再分层试试”，因此在原有限盒体／深度代理对照之外，增加去家具房间、椅桌和台灯三图分层。没有手工建立完整房间、修改商品机构或数据库。

## 入口与共同输入

启动生产演示后使用 `http://127.0.0.1:5181/`，公共参数为 `?product=typewriter-study&renderPipeline=realtime&studioMood=dark`：

| 追加参数                           | 实现                                           |
| ---------------------------------- | ---------------------------------------------- |
| 无，或 `loungeSpatial=infinite`    | 原无限远、固定 LOD 3.5 虚化全景，失败对照      |
| `loungeSpatial=box`                | 实体桌台＋有限盒体原图投影，无固定 LOD 虚化    |
| `loungeSpatial=depth`              | 同桌台＋实际 DA² 径向距离代理＋原图远盒补底    |
| `loungeSpatial=depth&loungeDof=1`  | 深度代理＋商品保护的真实深度景深               |
| `loungeSpatial=box&loungeLayers=1` | 同桌台＋生成去家具房间底图＋固定椅桌／台灯卡片 |

所有空间模式使用同一真实 v2 GLB、动作和完整相机输入。标准取景为整体、正面、侧面、绕背、顶部、漆面近景、0.6 分层和平铺；另拍缩远抬高的 `wide-table` 观察实体桌体，它不参与冻结相机对照。深度 DOF 只补拍整体、漆面、0.6 分层，以免将景深当空间修复。

原 Studio Small 05 HDR、商品曝光、三软箱及当前暖夜过渡保持。空间组的反射平面、接触阴影尺寸同步为 8.4×4.8，桌面高度不变；一轮修正将实验平面反射合成权重降为 0.28，普通实时对照仍为 0.5。不能把此批称为仅改变投影的单变量光学实验；额外桌体、分层透明边界和新图像内容也不同。家具图已有明暗，不额外完整打光。

## 资源与几何

- 实体桌台为带倒角石材厚板与独立桌体，顶面 -0.0192，底面 -2.4792。真实 GLB 所有顶点在 101 个结构状态的范围约 X -3.074…3.688、Y 0.0056…1.615、Z -1.723…1.723，8.4×4.8 桌面完整覆盖；此为采样覆盖，不宣称连续碰撞认证。
- DA² 使用官方代码 `d659838585f2bc9967c7e9367af573795271dbbb` 和固定权重，实际离线推理后导出 512×256 小端 Float32。浏览器不运行 AI。结果为相对径向距离，按地面校准，尺度不是米；详见 [运行清单](../public/studio/amber-lounge/spatial-v1/manifest.json) 与 [复现工具](../scripts/lounge-spatial/README.md)。
- 网格覆盖 512×255 分段，跨深度比大于 1.35 的三角形剔除，临近地面统一拟合桌底。原图远盒只能填黑洞，不能修复隐藏家具，也可能造成重复内容。经度采样窄带混合是显示保护，不改原 PNG 或声称严格无缝。
- [生成记录](../assets-source/amber-lounge/layers-v1/generation.json) 保存三个实际提示词。房间原生 1774×887 RGB，椅桌 1536×1024 RGBA，灯 1280×1229 RGBA；源与运行副本逐字节相同，不用数值工具修图。隐藏墙／地面为生成推断，不是实测。
- 椅桌与台灯是两个固定平面，真实 PNG alpha、alphaTest 0.2、depthWrite，按透明边界锚定椅脚与桌面。没有 billboard 或相机限制；斜视变薄、背面镜像及不完整遮挡都是显式限制，不能称完整三维家具。

## 生命周期与交付

唯一 TresCanvas、renderer 和绘制调度器保持。空间 owner 借用原全景、舞台及商品资源；只释放自身几何／材质。层图 loader 独占 Texture／ImageBitmap，卡片借纹理。取消、失败和迟到结果在挂载前清理；销毁先卡片和投影，后图片。切明亮隐藏投影／卡片并恢复原天空可见性，不重置镜头或商品。

可选 DOF 使用真实 view-Z，并随当前实例姿态刷新商品清晰范围；在线性 HDR 合成后、统一 ACES／sRGB 前执行。不是一支完全真实摄影镜头：特意把商品包围盒深度带保护为清晰，背景才逐步失焦。DOM 标签不参与。效果 RTT 与受检 r185 内部 Gaussian 节点由本地 owner 释放。

`demo:doctor/prepare/start` 新增两套清单的磁盘摘要和 HTTP 就绪检查，可发现缺失、LFS 指针、等长损坏及错误响应；不记录密码、权重或测试数据库。运行 PNG 与数值深度纳入 Git LFS，模型权重／Python 环境与临时图片录像不提交。

## 实测与工程结果

- `npm run check` 退出 0：89 个文件、493 项 Vitest；49 项演示工具、23 项实时 probe、36 项 v2 工具测试。保留两项既有 legacy Vue 属性命名 warning，没有 lint error。
- `npm run build`、`demo:stop → demo:prepare → demo:start` 和 `demo:doctor` 通过。实际 Spring Boot API 与生产前端运行于 8089／5181；构建保留既有 BVH 重导出与大包 warning。
- 离线 3 项深度 IO 测试与实际摘要／数值校验通过。DA² 网络推理 1.104 秒，PyTorch 峰值 allocated 3,030,804,992／reserved 4,127,195,136 字节；这只是本次制作计算，不是浏览器帧时间或显卡总占用。
- `node scripts/lounge-spatial-check.mjs` 在真实 Edge WebGPU、真实 API／GLB 上串行运行五模式全部通过：infinite 9、box 10、depth 15、depth-dof 5、layers 10，共 49 张 PNG、对应状态 JSON 和 5 段完整 case WebM。27 组冻结商品／材质／姿态／相机配对误差为 0。
- 实际验证唯一 Canvas／renderer／模型身份、mood 切换保持镜头与结构／外观、敲键、普通轨道操作、实际投影模式、两张卡片及去家具底图。五组无控制台错误或请求失败。每组观察到 74 个相机变化帧，这不是屏幕呈现 FPS。
- 深度模式在 1280×720、1440×1000、1920×1080、390×844、320×740 的控制和溢出检查通过；移动沿用同一 WebGPU 测试宿主，不表示移动默认会启用 WebGPU。
- `TYPEWRITER_V2_ADMIN_BACKEND=realtime node scripts/typewriter-v2-admin-check.mjs` 两项管理预览／取景检查通过，无数据库写入。该脚本回归普通实时管理预览，未将实验代理写入管理配置。

完整原始记录在忽略目录 `artifacts/lounge-spatial/`；本批日志分别为 `artifacts/lounge-spatial/browser-final.log`、`artifacts/lounge-spatial-assets/check-delivery-final.log`、`build-final.log`、`prepare-final.log`、`doctor-final.log` 和 `admin-final.log`。运行时临时复制到 `dist/artifacts/lounge-spatial/` 可通过 HTTP 查看；重新构建会清除此副本，需重新运行脚本并复制，不依赖 file://。

## 集中审阅与结论

初次实际深度图侧面出现椅子拉裂、三角缺口和远盒重复家具；宽桌默认近景看不见前沿。一次集中修正增加完整 512×255 代理采样、窄接缝保护、降低实验反射叠层，以及用户新要求的三张分层素材；最终抽查完整、侧面、背面、宽景、分层、平铺及层图绕行录像抽帧，保留所有失败证据。

| 项目           | 结果                                                                                   |
| -------------- | -------------------------------------------------------------------------------------- |
| 背景可辨认性   | 取消固定虚化后，墙、地面、家具布局比旧无限全景清楚；这不是重建精度成绩                 |
| 实体桌体       | 宽景可看到真实厚桌沿与承托体；默认近景仍大幅被桌面占满，桌体形态不明显                 |
| 单张径向深度   | 侧面椅面仍有拉裂／错误深度边缘，完整观察范围未通过                                     |
| 新生成分层     | 固定卡片保住家具完整轮廓，消除原图同位置重复家具；宽景可见独立台灯与边桌               |
| 家具空间可信度 | 没有完整侧背面与地面接触阴影，宽景仍有漂浮感、斜视厚度不足；未达到全范围自由观察要求   |
| 光照一致性     | 商品／桌面保留摄影棚环境，背景自身烘焙暖光；背面仍有大片浅白反光，未完成全房间光源校准 |
| 可选景深       | 商品保持清楚，远景逐步虚化；它不能修复几何或家具落地问题                               |

**结论：工程实验已完成，完整空间视觉验收未通过，默认不晋级。** 生成素材分层可继续用作远景和常用视角氛围，但当前两张平面不能代替任意环绕家具。若后续继续，优先补充近景家具的侧背面／简化实体承载、地面接触及一致照明，再调整默认构图；不继续靠多张同透视平面或大面积模糊堆叠。保留当前操作范围，没有通过限制相机或缩贴图制造通过结果。
