# 手势稳定性修订验收

日期：2026-09-14。原问题：用户能被检测，但指针抖动、捏合时目标丢失。

## 实现范围

- One Euro 自适应滤波应用于指针及掌心旋转；几何距离校正实际视频长宽比，掌部尺度取掌宽与两条纵向骨段长度最大值。
- 64px 进入 / 96px 退出的热点吸附，瞄准 120ms 后可捕获。捏合开始捕获已瞄准目标，不再要求指尖在收拢期间留在原 32px 热点。
- 捕获期间以掌心平移超过归一化距离 0.22 或持续超过 2.5 秒取消；模式切换、手动接管、隐藏目标及长时间丢手也取消。250ms 内缺帧暂停动作；丢失期间发生的松开不算确认，避免误触。
- 捏合需保持 120ms，松开需连续观察至少 60ms；确认后的反馈窗口防止连续重复触发。重置后必须先观察到张开姿势。
- 两步个人校准，每种姿势至少 10 个样本且覆盖 1.2 秒；采用分位数检查波动与两姿势区分度，12 秒超时给出重试提示。只保留当前页面中的阈值，支持取消与恢复默认值。
- 可展开本地骨架及原始/平滑指针诊断，显示距离比、阈值、最近推理耗时及返回结果频率；不将频率标为渲染 FPS。
- Worker 回传输入代次，旧模式/旧控制权的结果不会触发新模式；摄像头、位图和 Worker 清理沿用会话唯一所有权。

这些数值是当前实现的可调初值，不是社区通用标准，也没有被真人测试证明为最优值。

`npm run check` 和 `npm run build` 已通过。以下两个手势浏览器脚本均在 5181 生产预览再次通过；桌面与手机截图已查看。场景分包仍有体积提示，当前约 983 kB（gzip 270 kB），没有提高阈值隐藏。

- `npm run check`：TypeScript、ESLint、格式、Vue 文件行数、GLB 预算、31 项单元/作用域测试（包含新增展示适配器生命周期）。
- `npm run test:gesture-interaction`：Edge 模拟摄像头和合成关键点，真实页面输入逻辑；验证移动指尖仍能确认、掌心移开取消、两步校准/恢复默认、骨架显示、移动端布局。结果文件 `.impeccable/review/gesture-v2-results.json`。
- `npm run test:gesture`：实际本地 MediaPipe Worker 对空白帧推理，验证默认按需加载、摄像头流程及全部同源请求；这不是人体检测准确率测试。

## 真人复验入口

Edge → 开启手势体验 → 选择 → 校准捏合（先张开，再捏合）→ 张开两指 → 食指靠近热点 → 已瞄准 → 捏合 → 已锁定 → 松开。

按 `.ai/gesture-research.md` 的任务比较方案记录：20 次选择的成功/取消/误触、完成耗时、光照及左右手。另测试不打算选择时的自然移动，确认不会误触。真实准确率、疲劳感与真实摄像头端到端延迟仍未由自动化验证。
