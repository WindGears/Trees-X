## 实现边界

`studio/` 分离摄影棚设计、实体几何、反射、接触阴影和装配。低矮圆角地台顶面与原 groundY 对齐；墙面、窗框与软箱来自程序几何，PMREM 由同一布局生成。模型原始位置、结构与相机不因地台改变。摄影棚尺寸以场景单位计，不作为真实商品尺寸。

平面反射使用现有 renderer 离屏目标，1024² HalfFloat、4× MSAA、5×5 连续高斯柔化和 Fresnel 淡化；不新增 Canvas、渲染器或独立时钟。接触阴影为当前部件姿态的深度投影，1024² 两张目标、连续高斯模糊，仅动作变动后刷新，不把合拢阴影烘死。打字机不再叠加方向光硬阴影，其他商品的原阴影设置保留。

loader 保有模型几何、材质与纹理所有权；适配器释放摄影棚几何/材质、面光源库引用、反射和阴影目标；loadAdapter 释放专属 PMREM。离屏渲染恢复原目标、视口、剪裁、XR 与阴影状态；异常和重复清理另有单元测试。

漆面精修复用已有 Physical 清漆层，金属按实际 UV 条件使用各向异性或程序微粗糙度；贴花、配色与基准结构保留。工作台灯光提取为独立小组件；打字机采用注册摄影棚照明，钢琴/汽车照明和资产不改。管理预览也使用同一打字机摄影棚，取景回填仍只保存相机数字。

全部新摄影棚资源由项目代码生成，无新增第三方下载、图像贴图或安装依赖。原 GLB 来源与公开条件沿用已有资源记录。

## 验收记录

旧版对照来自仍运行的生产构建 `9444790`，1440×1000，保存全景、外壳后挡板与字杆近景，位于忽略目录 `artifacts/typewriter-studio/baseline/`。这些是当前真实资产的基线，不用概念图替代实机证据。

`npm run check` 通过：52 个测试文件、240 项单元测试，以及 48 项本机交付工具测试；TypeScript、格式、组件行数、源样板核查通过，legacy TypewriterStudy 的两条既有属性命名警告保留。`npm run build` 与 `demo:prepare` 通过，后者重新构建前端/可执行 JAR，并核验三件资源摘要。没有修改后端接口、配置版本或数据库。

首帧排查发现原 OrbitControls 的 change 回调把事件对象送入 Tres `invalidate(frameCount)`，在空闲状态令帧数变为 NaN；渲染循环仍活跃却不提交画面。已改为无参转发并同引用注销，真实控件的空闲事件/帧数/清理测试覆盖该回归。没有通过重建 Canvas 或跳过首帧门禁修复。

浏览器初轮覆盖真实 572 节点、同一 Canvas/renderer、全景/漆面/金属近景、试色、分层/平铺、A 键中间态、三个桌面尺寸、390/320px、减弱动态、上下文恢复与钢琴往返。反射目标读取为真实 HalfFloat 像素：试色和结构改变摘要，复原返回相同摘要。摄影棚可观察的 14 geometry、9 material 和 1 反射目标在恢复/切换中各释放一次；阴影目标另由单元测试核查唯一清理。

初审批次为 `artifacts/typewriter-studio/initial/`；一轮集中修正减轻橘皮幅度、改连续 25 点反射核并移除打字机叠加硬阴影，最终确认图片为 `artifacts/typewriter-studio/final/`。测试材料在 Git 忽略目录，生产代码不加入持续诊断。反射和接触阴影增加离屏渲染成本，本轮未采集帧时间或显存；不以目标参数代替成绩。

最终摄影棚脚本通过 9 组检查、25 张截图，浏览器错误为 0。新版生产入口已通过 `demo:prepare` → `demo:start`，保持 5181/8089；正式 API/资源来自本机，未修改商品数据。

生产构建的 `typewriter-lifecycle-check.mjs` 通过 7 组回归：鼠标/键盘/视角/聚焦接管、真实 instance 射线拾取、页面隐藏、WebGL 恢复、迟到选择、浏览器历史、模型加载失败重试。测试目录名称从真实 API 读取，生产 Vue 不提供 DOM 组件回链时仅在测试窗口遍历真实 VNode 上下文，不开启生产 devtools 或创建替代场景。

同一 renderer 三次钢琴往返后的打字机资源均为 291 geometry / 61 texture / 28 program；三次汽车往返均为 291 / 62 / 28。首次打字机为 59 texture；其他商品的共用灯光阴影目标预热会增加少量宿主缓存，此后未继续增长，不将暖缓存变化写成泄漏或声称初始数量完全相等。记录位于 `artifacts/typewriter-studio/lifecycle/`。

`npm run test:demo-production` 通过：禁止外网、允许回环连接，三件真实 GLB、动作/热点/导览、目录封面、三个桌面尺寸及 390/320px、接口失败重试，共保存 22 张生产截图；记录位于 `artifacts/typewriter-studio/production/`。本轮画面审查只进行了初审批次、一轮集中修正和一次最终确认，生产截图仅作构建回归，不再进行视觉迭代。

### A 键联动修正

真实 GLB 中 A 键对应 `part-070`，键杠杆为 `part-138`，字杆为 `part-023`。原字杆 1.15 rad 摆角在约 48% 行程穿入滚筒；在同一源几何上限定为 0.35 rad，保留键帽下压和杠杆转动。每次仍从基准姿态计算，不累积位移，未改变源 GLB、轴心、分层或平铺姿态。

`typewriterStrike.test.ts` 对真实顶点和局部矩阵进行核对：572 个静止部件与 GLB 局部矩阵一致（位置/旋转误差 <1e-11）。101 个行程采样中，旧 A 字杆的滚筒净距离为 -0.331654 源单位；修正后 A 最小 +0.117653，41 条具备完整按键/杠杆绑定的联动最小 +0.049053。另检查可见抬升、50 轮复原和分层/平铺兼容。剩余三条字杆没有有效杠杆绑定，不声明其击发支持。

浏览器通过自然 UI 击发与测试窗口中实际 GSAP 补间定位，记录 0/0.5/1 的侧视、正面、A 键帽和 A 字杆特写，再验证复原。键帽下压与峰值字杆出槽可见，闭壳遮挡部分链条。以上是滚筒采样净空、确定性与可见动作检查，不是全罩壳连续三角面碰撞认证，也不把演绎模型称为工厂校准打印机构。
