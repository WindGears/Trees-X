# 新版共同契约

2026-10-08。本文件定义目标行为，当前缺口见 restart-baseline.md。官方模板终稿优先于先前修订稿与旧阶段要求。

## 用户流程

首页默认机械打字机（2026-10-09 用户调整，音箱下架并退出正式计划），模型为主。目录左开，工具位于底部/右面板，同时只开一个面板。共同流程：选择 → 整体观察 → 关键部件 → 特色动作/支持时结构 → 返回全景。用户自由跳转，导览主动开始逐步推进，首屏不自动长演出。

左键旋转、滚轮缩放；面板滚轮隔离；热点/部件列表共用选择状态，主要工具键盘可达。拖动/缩放停止导览镜头，保留姿态。开关面板不重置；切换商品从新商品默认状态开始。

复位视角只恢复相机；返回全景合拢动作/结构、保留外观并恢复全景；还原商品恢复外观、动作、结构与相机。动作从基准姿态计算，无累积漂移。减弱动态直接到目标态。

## 三件脚本

本表是原流程样板的兼容测试契约，不再是当前三件正式资产排期。已迁入 Kimi 打字机使用 572 部件 GLB，具名“合拢整机/分层展开/平铺部件”控制连续进度，支持暂停、继续、复原；五步导览为整机 → A 键联动 → 分层 → 平铺 → 返回整机。单字母检索按尾部字母标记匹配，可同时得到对应按键和字杆；编号需输入 part- 前缀。音箱只保留历史/测试，汽车仍为工作台样板，精细版本在 legacy。

| 案例   | 观察点                      | 特色动作           | 主动导览                        | 结构条件                               |
| ------ | --------------------------- | ------------------ | ------------------------------- | -------------------------------------- |
| 音箱   | 整体、单元、控制件、外壳    | 外壳试色、旋钮转动 | 整体 → 单元 → 控制件动作 → 全景 | 必须外观分层与合拢，不虚构内部         |
| 打字机 | 整体、键盘、字杆、滚筒/滑架 | 简化按键/机构联动  | 整体 → 机构 → 击发演绎 → 全景   | 必须机构分层与复原，说明演绎性质       |
| 汽车   | 整体、车轮、车门、座舱      | 双门开合           | 整体 → 细节 → 开门/座舱 → 全景  | 支持时已验证运动组分离，不声称维修顺序 |

三件都提供观察、说明、导览和上述可复原动作。正式交付三件均用 GLB；程序化样板只验证共同流程，不能替代正式资产验收。必验动作不能因候选模型缺部件而直接删去：修复或选择可支撑动作的资产，缺口明确保留。不支持的可选能力隐藏；具体品牌、轴心、范围和说明在资产审核后确定。

展示区获得键盘焦点后，方向键旋转、+/−缩放、Home复位视角；不截获面板、按钮、输入框或视角下拉框按键。键盘观察同鼠标一样退出导览，只改变镜头。不支持WebGL2或渲染器启动失败时，显示真实API的封面、说明与部件内容，保留目录；状态为content，不能算作3D首帧ready。接口失败仍显示错误及重试，不回退假数据。

## 配置和生命周期

ProductPresentation 保留 source、能力、camera/views/hotspots/finishes/actions/structure/guide，兼容v1/v2/v3。结构版本不等于发布版本。热点业务ID映射唯一节点及可选局部锚点，随部件移动；节点组尚未实现。新商品优先补资源/配置；复杂机构注册组合行为或验证动画，禁止数据库执行代码。

### v3可逆探索（本轮原型）

actions.kind新增progress；motion包含duration（完整行程秒数）、openLabel/closeLabel和tracks。轨道包含唯一节点node、range=[起点,终点]（0≤起点<终点≤1），及translate/offset或rotate/单位axis/angle（弧度，绝对值≤π）。同一节点同一变换通道不能被两条进度轨道或旧行为同时控制；位移和旋转可独立组合。轨道从加载时初始局部姿态计算，不依赖先前播放方向。hotspots.anchor为可选局部Vec3，guide.progress可指定actionId/value作为停留观察点。

音箱structureActionId=explore-layers，旧展开意图映射至进度动作；前面板、单元、外壳、旋钮分阶段移动，旋钮可独立转动。汽车open-doors同时控制两扇门的旋转，旧分離操作仅控制位移。打字机仍沿用v1联动。

结构与动作面板提供0—100%、步长0.1%的原生滑条、百分比、展开/打开、暂停/继续、合拢/关闭及动作复原。默认不播放，全程2秒，部分行程按距离缩短。手动定位立即取消补间；旋转、缩放、视角、聚焦暂停播放并保留姿态，必须主动继续。关闭面板保留状态；切换商品清空进度。动作复原仅归零该动作，复位视角仅镜头；返回全景/还原商品仍使用既有恢复范围。

页面隐藏暂停，返回不自续；上下文恢复保留当前选择的进度，停在暂停态。减弱动态下自动操作直接到目标，手动定位可用。实时进度只在场景及工作台局部会话，Pinia保存意图。公开路径不变，Flyway V5仅升级与初始默认配置匹配的音箱/汽车，跳过并记录自定义配置。

请求/解析/材质/首帧均检查商品和代次；迟到释放，失败重试，首帧后开放操作。单Canvas/renderer，各资源明确释放方，按需加载，页面隐藏暂停。

## 四类数据

- 管理员：唯一账号、BCrypt密码散列，本地环境初始化；启停角色扩展未实现。
- 分类：名称、排序、并发版本，被引用时限制删除；不引入额外启用开关。
- 商品：唯一slug、分类关联、中文名、说明、封面、排序、上下架。
- 展示配置：商品一对一，结构版本、校验JSON、更新时间及并发版本。

资产完成度 prototype/formal 与可见状态 listed/unlisted 分开。分类/状态追加迁移，保留记录，不能把当前分类字符串当成已有分类实体。

开发者准备同源模型/纹理/封面，数据库保存资源引用与来源说明（作者、来源链接、许可及修改记录，不虚构缺失信息）。开发用manifest/摘要可保留，无需业务资源表/上传/快照。加载会话使用本次配置，后台编辑后重新加载读新版，当前场景不热替换。

## 实际 API 和管理流程（阶段D）

公开GET /api/v1/categories、/api/v1/products?q=&category=、/api/v1/products/{slug}，仅返回上架商品，下架详情按未知商品处理。沿用数组列表契约；三件目录不增加分页。分类读取返回有上架商品的分类，管理端读取全部分类。

管理/api/v1/admin/：GET session/csrf；POST session/login（表单账号密码）；GET session；POST session/logout。GET/POST products，GET/PUT products/{slug}；POST products/preview校验当前输入但不写数据库；PUT products/{slug}/visibility携带{revision,listed}。基本信息与展示配置整体验证并事务保存，避免两个保存接口产生半更新。GET/POST categories、PUT/DELETE categories/{id}（删除携带revision查询参数）。旧拟定的独立presentation/status路径未提供，以本契约和server/README.md为准。

管理员可预览下架和未保存内容，复用同一场景宿主。更新携带revision，旧版本409；配置/字段400；未登录读401，无CSRF的写403。新建默认下架，商品slug不可修改。前端提示保存后再上下架。管理员不能删除被使用分类，现阶段不提供商品删除或归档。

管理编辑按基本信息、部件热点、外观、镜头、动作、导览、高级配置分区。常用项为表单，高级完整JSON必须显式应用；未应用或无效文本阻止保存/预览。新建先选已有配置起点；条目ID自动生成并保持稳定，引用项须先解除导览引用，至少保留一种外观与perspective视角。返回全景步骤保留组合配置但不执行其余项。失败/冲突/重新登录保留本地输入，重新读取/返回列表/退出有明确丢弃提示，不自动保存。

预览左键旋转、滚轮缩放，仅管理预览开放右键平移。回填目标为默认取景或已有预设；采集前退出导览并暂停相机/动作补间，只读取当前代次首帧就绪的真实位置和目标。隐藏、加载、错误、上下文丢失禁止采集；恢复后重新注册数字快照桥接。默认回填同步camera.position/target及perspective视角，命名回填只改该视角，缩放范围不变；不回填配色/动作/分层，不写数据库。手动保存成功后以服务端返回配置/revision为基线，前台重载读取新配置。会话失效卸载预览而保留草稿。

Session、密码散列、CSRF与同源访问。闭环：准备资源 → 登录 → 编辑 → 校验 → 预览 → 上架 → 访客观察 → 修改后重载 → 下架。无复杂审批、草稿快照、回滚。

## 验收
