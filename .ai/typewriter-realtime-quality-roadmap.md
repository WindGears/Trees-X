## 当前接入约定

用户要求继续 WebGPU，每个工程成功节点及时落实到可用入口，画质由本人肉眼判断。旧记录中的整体画质未通过继续如实保留，但不再作为阻止下一项独立实现接入实时入口的统一门槛。仍保留同输入对照、明确回退、互动与生命周期检查；不将工程 PASS 写成视觉提升或 P95 达标。

显式 `?product=typewriter-study&renderPipeline=realtime` 默认接入已核验的 v2 材质包，`typewriterAsset=v1` 为旧材质对照；普通 WebGL、其他商品、自定义包、HTTP 与数据库不变。本批优先给 signedSpatial 原有八 tap 增加像素 IGN／成功完整帧 golden-angle 旋转，`reflectionKernel=static` 保留旧核。采样数量、半径、Physical 参数、唯一 renderer 和时钟不改，phase 在历史成功 commit 后推进，失败或取消复用。这沿用 Three MIT 核旋转思路；本批 check、生产构建与 API 启动、真实 WebGPU 两核六取景、v2 动作／复原／重复加载及管理取景检查通过，整体画质待用户评定，实际呈现预算仍待验证。证据见 [WebGPU 接入记录](typewriter-webgpu-rollin-validation.md)。DDGI／FidelityFX／BVH 尚未接入，不因改入口宣称完成后续节点。

## 目标与上线约定

- 保留自由观察、敲键、聚焦、分层、平铺、导览和管理预览；动态过程中持续提供高质量画面，不等待路径追踪或降噪累积。
- 旧静止路径图的材质质感、光比和反射氛围是视觉方向；当前 UI、天空盒与地台形态保留。路径追踪是参考，不承诺逐像素或任意运动状态等效。
- 只升级打字机。钢琴、汽车保持原管线；不追加展品、手势、管理功能、数据库迁移或 CI。
- 本机 1440×1000 的目标为实际呈现间隔中位 ≤33.3ms、P95 ≤45ms。JS 提交间隔、GPU 时间和实际呈现分开记录；缺少呈现证据时保持待验收。不自动缩分辨率、缩贴图或降低画质。
- 普通入口继续增强 WebGL。实验只使用 `?product=typewriter-study&renderPipeline=realtime`；全部画质、互动与稳定性通过并经用户本人走查后，才切换支持 WebGPU 的桌面打字机默认。

2026-10-14：已完成显式 HalfFloat RTT 修复与四路 GPU 诊断，Cline 产出统计提案，由 Codex 审查／实测。六个修复前后取景输入一致；近景点噪与过滤残差仍待修正，完整节点一未通过，不开始后续材质／DDGI。详见 [HDR 修复记录](typewriter-hdr-rtt-validation.md)。

固定整机、漆面、金属、键帽、0.6 分层、平铺六个取景。先比较地台原始反射纹理与最终合成，定位倒影变浅、白点和轮廓损失。商品与舞台在线性 HDR 中合成，最终统一一次 ACES／sRGB 输出；天空背景单独明确输出契约。核查文字贴片透明孔、深度及 G-buffer 写入，不通过扩大模糊掩盖噪声。

以旧参考的 Studio Small 05 HDR、曝光和软箱作为初始共同布光，最多一次集中调整后冻结清单。运行副本制作完成后，再生成同资产、灯光、曝光、相机和姿态的 128 样本降噪与 1024 样本原图；旧图不直接当作公平误差指标。

通过条件是地台轮廓完整、无新增明显白点、文字和细边不弱于原 WebGL，六个取景的共同输入可复现。证据与未通过项记入 [节点一验收](typewriter-quality-node1-validation.md)。本节点未通过，不叠加 DDGI、FidelityFX 或 BVH。

### 节点二：独立 UV 与材质运行副本（工程检查已完成，视觉待本人判断）

保留 v1 原件和动作文件，另建候选 v2 包；不整机合并、减面、改轴心或机构。核验确认十个 primitive 缺 UV：6 个 enamel、2 个 steel、1 个 ribbon、1 个 red，各自只有一个表面引用，并非全部共享实例。对规则表面使用确定性局部投影，其余使用现有 xatlas；已有 UV 和字符贴图保持。按需要生成 MikkTSpace 切线并核对手性。源资产全部 298 个 primitive 未存储 TANGENT，但 Three 可在有 UV 的表面使用导数 TBN；显式切线制作与缺 UV 修复是不同工作，不能把未存储切线误称为法线贴图完全不可用。详细口径见 [资产核验](typewriter-asset-audit.md)。

漆面、拉丝金属、铸铁使用共享 2048²无缝微法线／粗糙度图，拉丝增加方向图；保留 Physical 清漆与各向异性，首轮 PNG 不同时引入压缩变量。Blender 只操作独立制作副本；仅烘焙部件自身稳定遮蔽，不烘死展开后的互遮挡。

要求 572 语义部件、2257 表面映射、动作文件摘要保持，三角形位置／法线误差 ≤1e-6，材质近景与动作均通过。UV 接缝可拆顶点，但不得改变空间形状。唯一允许改变的源字符图片是用户授权的 image 50／decal-62 铭牌，重新生成 1024×416 的 WindGear 金色斜体图；其他字符图片、贴片坐标和深度规则保持。当前共享微表面采用确定性程序数据，没有照明或部件互遮挡烘焙；Blender 制作母版单独保存在忽略的 artifacts 目录。新资产通过之后再制作同输入路径参考，未完成的参考不报已通过。
