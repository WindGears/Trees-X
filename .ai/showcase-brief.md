# 展示页实施简报

模式：Experience。范围：用户已批准的 Trees X 桌面体验优化方案。当前目标是高配桌面的沉浸式三维商品展厅，后台、AI、多人空间、截图分享不在本轮。

## Direction contract

THESIS：让访客先欣赏商品，再自然探索细节。对象主导，操作按需出现。

OWN-WORLD：近黑产品摄影棚；音箱的银色金属、赛车的暖色潮玩、植物的自然绿分别表现。舞台与材料共同塑造气质。

STORY：看见商品 → 拖动、缩放或打开外观/细节/结构/手势 → 用户主动导览 → 返回全景；退出面板保留观察状态。

FIRST VIEWPORT：中文名称 36–48px，一句介绍与辅助编号。唯一 Canvas 占据右侧主要面积；底部四个探索入口，命名视角与缩放组成独立紧凑工具条。侧栏默认关闭，完整控制台由顶部打开。

FORM：遵循用户已固定的 Apple / Legions 产品中心方向、桌面画质规格、三件主展品与七件目录。旧版首屏常驻完整控制台要求被明确替换。

FINISH：保留真实浏览器与模型身份验证、桌面截图、兼容检查、资源许可和工程检查。真人手势可用性不能由合成测试代替。

## 2026-09-23 音箱视觉样板扩展

范围限于已确认的桌面音箱摄影棚增强与用户主动触发的 6–8 秒短片。沿用当前品牌、中文身份区、单 Canvas 与按需面板；其他六件商品的舞台和交互保持既有范围。

THESIS：让金属的光、旋钮的近景与外观层次成为主动欣赏入口。

OWN-WORLD：现有近黑摄影棚内，以条形面光、细纹金属和清晰轮廓塑造音箱；仅音箱移除发光环、粒子和扫描层。材质表现属于原创概念模型，不推断真实工艺或声学性能。

STORY：「观看演绎」→ 旋钮特写 → 完整轮廓 → 外观分层 → 合拢并提示自由探索。实现总长 7.8 秒，界面显示「8 秒」；章节文案随镜头更新，正常结束保留配色。中断停在当前镜头与分层状态，减弱动态直接到完整外观。

FIRST VIEWPORT：完整音箱先静态到位；入场只做灯光揭示，不自动运镜。左侧说明下增加浅银演绎按钮，原有探索入口和视角工具继续可用；390px / 320px 保持纵向兼容。

FORM：镜头、灯位和分层共用一条局部 GSAP 时间线，复用已有相机与控制器。架构职责、唯一释放方及接手约束沿用 [音箱主动演绎架构](architecture.md#音箱主动演绎)；新增灯光、材质和模型细节的成本只按实测资产预算与回归证据记录，不承诺通用设备性能。

FINISH：证据与边界集中于 [音箱样板验收](speaker-film-validation.md)。音箱最终视觉复核为 `ship`，结论仅覆盖该样板；本轮不扩展赛车和绿植短片，后续先完成用户验收。真人手势稳定性仍待真实设备验证。
