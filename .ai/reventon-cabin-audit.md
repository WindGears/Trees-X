# 座舱暗部隔离检查（2026-10-27）

## 结论与接入决定

摄影棚和座舱视觉仍未通过。撤下本地未提交的 `carStudioCabin=lift`
候选：18661 乘 8、19771 乘 16 的底色补偿虽通过参数/动作检查，但实际
截图没有足够明确的整体收益，不作为已经修好的材质发布。源码恢复至已提交
材质方案；实验补丁和截图留在忽略目录，不覆盖原模型和贴图。

## 实际证据

- `artifacts/car-showroom/cabin-r11`：原版与倍率候选各六个取景，工程通过，
  `visualPassed: false`。对照未改变几何、法线、粗糙度、AO、其他材质或动作。
- `cabin-isolation`：同一实际座舱姿态检查底色倍率、全车 AO 强度归零、两者
  组合及皮革红色自发光标记。标记确认 18661/19771 对应仪表台、方向盘局部
  和门板等目标。关闭 AO 可见部分金属变亮，但没有解决皮革整体偏暗。
- `cabin-light-isolation`：关闭间接光修正、用线性 0.035 常量临时替代两类皮革
  底色，以及侧灯强度 3.2→12.8。常量使部分皮革轮廓略清楚；单纯侧灯增益
  没有足够整体收益。它们均非成品：常量移除了底色纹理，侧灯试验没有同步
  改灯板或重烘焙反射源，也没有重新求解完整 DDGI，不作为一致照明对照。
- `cabin-audit`：用正式可重跑工具再执行九种状态，核对唯一 Canvas/renderer、
  GPU 错误及结束时材质贴图身份、颜色、AO、自发光和侧灯强度精确复原。
  测试完全后台无头；临时改动仅存在于专用浏览器会话。

这些实验缩小了排查范围，不能证明 AO、DDGI 或受光在所有视角下均正确。
截图没有以亮度差或工程断言替代视觉通过，也没有生成性能结论。

撤回候选后，147 个测试文件、936 项单元测试及生产构建通过。
`npm run check` 类型与 ESLint 通过，格式阶段仅被已有用户文件
`PERFORMANCE_OPTIMIZATION.md` 阻断；未修改该文件。九状态浏览器报告
`passed: true` 只表示诊断执行与复原检查通过，`visualPassed: false` 保持。

## 颜色编码误判已排除

原 4K 16-bit 皮革 PNG 数值很暗，但不能把烘焙日志的 `image.pixels` 当作
线性结果：其目标图已设为 sRGB。使用本机独立 Blender 空场景、已知线性
发光颜色 (0.02, 0.05, 0.18) 的 EMIT 烘焙验证：sRGB 目标像素约为
(0.151704, 0.247801, 0.461355)，保存 PNG 也对应这些编码值；线性目标
的像素为原输入，但 save_render 输出同样正确编码。证据在
`artifacts/car-showroom/cabin-color-probe`。因此本轮不修改源图颜色空间，
不宣称发现了重复 sRGB 解码。

## 重跑与下一步

运行生产预览后执行 `node scripts/reventon-cabin-audit.mjs`，默认写入忽略的
`artifacts/car-showroom/cabin-audit`。可用 `TREES_CABIN_AUDIT_OUTPUT` 指定
新的目录保留历史。静态次数是诊断等待帧，不是性能或物理收敛证明。

下一轮按真实受光方向与座舱取景组织灯位候选；若改灯位，则可见灯具、
面积光、反射环境共同更新，再比较整车与座舱。继续保留材质原件，禁止用
删除 AO、全局曝光或永久自发光冒充照明修正。摄影棚通过前不进入世界空间
车漆反射节点。
