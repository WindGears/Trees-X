# 打字机天空盒与默认取景收束

2026-10-11。用户指出摄影棚墙窗在宽取景和自由转动中暴露布景边界。本轮在 `56a05cb` 质量样片上收束背景，不重做工作台，不更换模型、材质或动作；钢琴与汽车保持现有舞台。

## 当前实现

- 主舞台只包含圆角地台、地面和六面 BackSide 天空盒。背景统一按方向高度插值，顶点投影去除相机平移并落到远平面，没有六张图的接缝，也不会露出有限墙的背面。背景不受雾或 ACES 再次压色，不写深度；由舞台唯一释放。
- 地面保持近处真实受光，14—30 场景单位内逐渐淡出；大平面边缘不进入正常观察范围。原背墙、窗框和可见灯板全部移除。
- 可见背景和反射照明分开。独立临时捕获场景沿用三块 HDR 软箱与面积灯布局，捕获底光为可见背景的 0.35，保留黑漆和宽高光的对比。创建 PMREM 后释放临时背景、几何、材质与灯；loadAdapter 继续拥有返回的环境目标。主背景和捕获背景不共享可变颜色或资源。
- 原实时柔化平面反射、姿态更新接触阴影和有限 A 键联动保留。没有新增 Canvas、renderer、动画时钟、纹理下载或离屏目标。
- 默认 `camera.position` 与 `perspective.position` 同步为 `[1.7248, 1.44152, 2.5604]`，原目标 `[0, 0.47, -0.15]` 与 FOV 38 保留，相机距离为原值的 0.88。展开、平铺及其他命名视角和热点镜头偏移不改。
- 源初始配置和生成器同步，本机商品仅在确认仍为旧默认配置后通过已有管理 API 保存；公共读回与完整配置比较确认仅上述两个位置变化。后端重启后仍为新取景。没有运行时镜头覆盖，没有修改 Flyway、接口或配置版本；后续管理员自定义镜头按配置原值使用。Git 同步不代替 MySQL 备份。

## 边界

背景为程序化中性摄影棚天空盒，不是新增户外天空贴图，也不宣称实景 HDR 摄影资源。默认取景扩大主体，不自动跟随拆解抢相机；任意结构状态仍可自由观察并主动使用展开/平铺镜头。未测本轮帧时间或显存，不把减少可见布景网格写成实际帧率成绩。主观审美仍接受本人反馈。
