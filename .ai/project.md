# 当前项目与阶段

2026-10-01 用户确定新方向：**商品目录 + 统一三维工作台，先验证展示流程与整体架构，再逐件换正式模型。** 首页默认音箱，模型优先、工具按需出现；自由鼠标观察为主、手动导览为辅，不自动演出或环绕。不在本轮继续高精汽车材质制作。

## 当前交付

1. 共同契约与三件商品脚本已确定并经过前后端契约测试。
2. 工作台及 Spring Boot/MySQL 真 API 已连通。三件程序化流程样板：form-01 / typewriter-study / reventon。
3. 操作、切换、错误恢复、单 renderer 与桌面/移动基础浏览器流程已验证。详见 [工作台验收](workbench-validation.md)。

后端 Spring Boot 4.1.1、Java 17、Maven Wrapper、JPA、Flyway、MySQL 8；独立 trees_x / trees_x_test，不复用博物馆业务表。基础信息和版本化展示配置分别持久化，首轮只读 API。连接参数走环境变量或 Git 忽略的 server/.env.local。

前端保留 Vue/Tres/Three/GSAP/Pinia，单一工作台 Canvas。Pinia 保存配置与意图；模型/材质/几何/controls/动画由场景生命周期拥有。运行时无静态样例回退；后端异常必须展示重试。页面 UI 与 Three 分层，Vue ≤300 行。

## 下一步与边界

本轮到此框架验收结束。正式模型按音箱 → 打字机 → 汽车逐件接入，同一适配器执行外观、热点、动作、结构和复位。每件通过后才进入下一件，不复制新页面。手势、管理后台、鉴权和上传分别排期，不与模型接入混写。

旧商品和实机资源保留在 legacy 入口。旧非样板 ID 深链接继续进入旧版，新工作台不预加载其 GLB/HDR/手势。旧版相机/画质规则只对 legacy 生效。

入口与约束：PRODUCT.md 是产品事实；DESIGN.md 是已实现视觉；[工作台契约](workbench-contract.md)与[架构](architecture.md)说明接口与所有权。旧阶段/影片/九商品独立舞台记录移入 [2026-09 历史](history/2026-09-project.md)，不作为当前待办。

继续开发：先说明架构位置、职责、性能影响、扩展方式；完成当前阶段验收后再扩展。执行 npm run check/build、受影响生命周期测试及真实 API/MySQL 检查；不得编造数据、商品参数、接口和性能成绩。
