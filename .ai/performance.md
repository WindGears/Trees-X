# 性能预算与验收

2026-10-02：下表为 legacy 预算。正式展品不继承 5 MB/10 万面/2K 限制，按资源包单独声明。画质优先，保留原始母版；记录冷加载、帧时间、纹理字节与资源数量。工作台仍按需渲染、按需加载、唯一释放，不自动降画质。阶段 1 不宣称完成汽车显存优化。

以下是设计预算，不是已测量成绩。

| 项目            | 当前策略/预算                                                                 |
| --------------- | ----------------------------------------------------------------------------- |
| GLB 体积        | 目标 ≤ 5 MB                                                                   |
| 单模型三角形    | 硬上限 100,000                                                                |
| 常规 draw calls | 目标 ≤ 60，资产检查记录实际网格数                                             |
| 贴图/HDR        | 贴图目标 ≤ 2048²；HDR 硬上限 2 MB，当前 1,723,695 bytes                       |
| DPR             | 高配桌面 cinematic 上限 2，Composer 固定 1.0 输出；eco 固定 1                 |
| 帧时间          | 1440×1000 连续交互 10 秒：中位数 ≤20ms、P95 ≤33ms                             |
| 空闲渲染        | eco 按需；cinematic 仅展示区可见且页面在前台时连续渲染                        |
| 后处理          | Half-float、8× MSAA、1600 粒子、Bloom、Vignette、ACES；桌面不按 tier 自动降级 |
| 加载            | WebGL 与 cinematic 模块异步 chunk；GLB/HDR/手势资源均同源                     |

## 验证方法

`npm run model:check` 检查 GLB 结构、三角形和体积。`npm run test` 验证预算拒绝、归一化和去重释放。`npm run check` 检查类型、lint、格式、Vue 行数。

浏览器检查：桌面/移动端；操作、失败重试、键盘、减弱动态、模型加载状态。真实 GPU 帧时间与重复挂载内存曲线在 Phase 2/4 录制，不把本地编译或截图称作跨设备性能测试。

最新桌面电影画质配置为完整输出比例、8× MSAA 与 1600 粒子。运行时继续记录帧时间，但按用户要求不再根据 tier 自动降低视觉质量。移动、减弱动态和能力不足设备仍使用 eco 兼容路径。
