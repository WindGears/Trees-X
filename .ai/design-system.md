# 视觉实现约束

## 当前明亮／暖夜环境（2026-10-15）

实时 WebGPU 打字机增加原位“明亮／暖夜”切换，沿用方案 C 的布局和玻璃工具。暖夜为放松的琥珀酒吧氛围，以生成的 LDR 全景作可见背景、生成的单块岩板底色配独立数值粗糙度／微法线作地台；不使用扫描材质或烘死商品倒影。背景固定 LOD 3.5 虚化，接缝和极点仅做采样保护，不能称为真实 DOF、专业 HDR、源图完全无缝或概念图等效。

原 Studio Small 05 HDR 保持，三块软箱的颜色与强度随环境过渡；明亮恢复既有舞台。过渡约 0.42 秒，由旧舞台时钟推进 GSAP，快速操作取消旧补间，减弱动态直接到目标。首次暖夜异步加载四图，失败给出重试，保留真实模型和观察操作。明暗切换不重置镜头、配色、分层、当前部件或动作，不增加 Canvas／renderer，也不改其他商品和兼容入口。

实现参数仍以 `DESIGN.md` 和代码为真值。本批实机与画质验收由主代理更新于 [暖夜运行验收](amber-lounge-runtime-validation.md)，此处不写测试通过或性能成绩。此前深灰绿暗色试用为历史；下方方案 C 首次发布时的配色与场景范围也按其日期阅读。

## 方案 C 初始规范与后续历史

2026-10-11 用户选择方案 C：浅银灰、淡灰绿、极简毛玻璃的漂浮式工作台。访客入口使用 `wb-floating`，保留唯一三维舞台、左侧真实商品快速栏、按需打开的单活动面板与底部两行工具。默认打字机，目录为打字机、钢琴与汽车三件真实 GLB。管理端、管理预览与 legacy 本轮不改主题。正式尺寸、字体、颜色与动效参数记入根目录 `DESIGN.md`，不维护两份 token 真值。

此前深蓝灰/冷银工具和蓝紫科技光为历史访客方向；深蓝灰基础样式继续用于管理端与管理预览，不再约束 `wb-floating`。方案 C UI 阶段未制作完整展厅。随后打字机摄影棚样片加入程序地台与反射，墙窗方案按用户反馈撤除，当前使用无缝银灰绿天空盒；软箱只参与反射环境捕获。仍以实机截图验收，不能把生成概念图当作实机品质证据。

- 访客先看清产品，其次发现拖动、视角、缩放和复位。
- 浅灰底色承托模型，材质、照明、动作与正式资源保持原有通道；本轮只统一访客背景与地面色，不宣称模型精度提高。
- 玻璃集中于快速商品栏、单面板和工具条；正文分组靠间距与细线，不叠加玻璃卡片。无背景模糊支持时使用实色回退。
- 灰绿服务选中与键盘焦点，不以持续光效或浮动动画装饰整个页面。
- 面板进出和导航指示由 GSAP 管理，快速切换取消旧补间；淡出面板立即 inert，关闭恢复入口焦点。
- 面板打开时只调整投影构图，不改用户相机位置/观察目标，不重置配色、结构或当前部件。布局边界变化后热点继续按真实投影更新。
- 字体和图标统一，中文正文易读。无虚构价格、功率、续航与促销。
- 所有功能有键盘入口与明显焦点。状态信息不只依赖颜色。
- 移动端使用横向快速栏与底部单面板，保留核心操作；加载与失败保持同一舞台空间。桌面优先，移动仅作基础兼容。
- 遵循减弱动态；页面隐藏停时钟，组件卸载清理 GSAP、监听和投影构图。新增 UI 不增加逐帧 Pinia 状态或新的 renderer。

## 历史方向（不作为方案 C 要求）

2026-10-01：原共同工作台为深蓝灰、左目录/右单面板和底部工具；当时音箱/打字机/汽车仍为流程样板。默认无完整控制台或自动演出，手势未进入新入口。旧独立三主展品舞台与电影画质要求仅在 legacy 保留。

2026-09-21：默认沉浸浏览与单活动面板已经替换常驻完整控制台。当时中文名称 36–48px、正文 14–16px、辅助文字不小于 12px；三件主展品采用金属、潮玩、自然舞台，植物不显示发光圆环。英文编号仅辅助、资源许可归入作品信息等事实表达规则继续有效；当前尺寸以 DESIGN.md 方案 C 记录为准。
