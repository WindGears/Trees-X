# 单商品完整探索验收

日期：2026-09-15。对象为原创 FORM / 01 音箱概念样品。

## 已实现

- 雾银、石墨、香槟三种外壳概念配色。外壳使用独立材质副本，驱动单元金属框和旋钮不被共享材质串色。
- 低音单元、高音单元、顶部旋钮三个稳定命名部件。按钮和热点都进入同一聚焦镜头，缩放围绕当前焦点。
- 外观部件展开与合拢。所有位移从 GLB 原坐标快照计算，可反复切换，不累积漂移。
- “观察外观 → 走近细节 → 展开结构”三步手动导览，支持前进、后退、退出和完成。
- 重置恢复雾银、完整外观、初始立体视角并关闭部件说明。
- 鼠标首次按下立即中止镜头补间；手势确认复用部件聚焦；减弱动态直接到达最终状态。

## 验证证据

- `npm run check`：TypeScript、ESLint、Prettier、41 个 Vue 文件行数、GLB 预算和 31 项测试通过。
- `npm run build`：生产构建通过；ProductViewer 分包约 990 kB（gzip 273 kB），仍保留体积提示。
- `npm run test:experience`：Edge 桌面 1440×1000、手机 390×844 与窄屏 320px；验证三种配色像素变化、结构像素变化、三个热点居中、聚焦缩放、导览往返、完整重置、镜头中断和减弱动态切换。报告为 `.impeccable/review/experience-results.json`。
- `npm run test:browser`：原有视角、缩放、节能、模型失败重试、WebGL 上下文恢复、无 WebGL 降级与键盘入口通过。
- `npm run test:gesture` 和 `npm run test:gesture-interaction`：本地 Worker、虚拟摄像头、合成手势确认、取消、校准和移动端布局通过；未开启真人摄像头。

## 边界

当前 GLB 的 `Chassis` 是实体外壳，没有主板、电池或真实声学内部。结构模式因此只称为“外观分层示意”。三种配色、部件说明与镜头位置都是该原创概念样品的展示配置，不能作为真实商品参数。真人手势稳定性仍需用户复验。
