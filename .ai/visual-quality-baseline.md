# 画质方案与比较基准

2026-10-11 冻结 B0。本文记录该历史版本及比较规则，方案 C 是访客界面的视觉方案，不是渲染器方案。2026-10-12 已完成后续材质/结构精修与独立同输入比较，正式入口仍保留增强 WebGL2；新结果见 [精修验收](typewriter-quality-validation.md)、[渲染比较](render-pipeline-comparison.md)，不覆盖 B0 图像或摘要。

## B0 冻结时的方案

共同宿主是唯一 TresCanvas / WebGLRenderer，ACES 色调映射、sRGB 输出、按需渲染、DPR 上限 2。B0 工作台没有 Composer、SSR、SSGI、WebGPU 或路径追踪；旧版 Effects 和独立 Demo 的功能不能算入正式工作台。后续独立渲染比较也不表示生产工作台已迁移后端。

| 展品   | B0 材质、反射和照明                                                                                                            | 当时未完成                                                     |
| ------ | ------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------- |
| 打字机 | 清漆、程序微法线/粗糙度、部分金属各向异性；专属 PMREM 软箱环境、三盏面积灯、1024² 柔化平面反射、1024² 姿态接触阴影；程序天空盒 | 物体之间的实时反射、实时全局光照、离线物理参考对照             |
| 钢琴   | 源 GLB 参数化 PBR/清漆；RoomEnvironment 与发光板 PMREM；共同工作台灯光及阴影图                                                 | 未接入打字机摄影棚、平面反射与姿态接触阴影；近景资产细节仍有限 |
| 汽车   | 原 PBR/法线/AO 贴图、玻璃 transmission；EXR PMREM、两盏面积灯、2048² 姿态接触阴影                                              | 未接入打字机摄影棚和平面反射；原烘焙 AO 不代表实时全局光照     |

PMREM 为材质提供预过滤环境反射，地台 Reflector 另行渲染镜像画面；两者不等于任意部件间的实时互相反射。打字机现有贴图主要是贴花，钢琴主体依赖材质参数，汽车拥有更完整的表面贴图。比较结果必须区分资产、布光与渲染能力，不能把更换渲染器当作补齐资产细节。

B0 画面条件为 1440×1000、实测 DPR 1、曝光 1、默认缎黑。默认相机位置 `[1.7248, 1.44152, 2.5604]`，观察目标 `[0, 0.47, -0.15]`，FOV 38。该投影还受 `viewportFraming` 的 zoom 和 view offset 影响，不能只锁定相机位置。

## 后续比较规则

1. 保留 B0，新版本使用独立输出目录。生产检查可用 PowerShell 环境变量：`$env:CHECK_URL='http://127.0.0.1:5181'`、`$env:STUDIO_CHECK_OUTPUT='artifacts/visual-quality/B1-typewriter'`，然后运行 `npm run test:typewriter-studio`。现有脚本会记录真实场景与截图，但不会自动把新配置锁成 B0。
2. 正式拍摄前核对同一 GLB/贴图/动作资源、完整配置、实际相机 position/target/quaternion/FOV/zoom/view offset、画幅/DPR、面板开关、外观和结构进度。等待字体、模型和补间稳定；不得把随机击发峰值截图纳入固定姿态比较。
3. 同一轮只改变一个明确因素，例如漆面粗糙度、环境布光、反射算法或阴影算法。测试渲染算法时，资产、灯光、曝光与构图保持；改变资产时则明确标为资产升级比较。整体重新布景属于综合效果比较。
4. 全图并排查看，再取相同像素坐标的 100% 近景，禁止单边放大、调色、锐化或换背景。记录改善、退步与未解决项，由本人确认是否采用。
5. 检查黑漆是否发灰/死黑、高光是否过曝、金属是否有塑料感、文字和边缘是否清楚、反射是否错位、阴影是否漂浮/过脏，以及展开后的阴影是否随姿态变化。画面正确性与审美分别记录，不预填质量分数。
6. 固定静帧后再检查旋转和部件运动中的闪烁、反射跳变、阴影迟滞；帧间隔、冷加载和资源计数另列运行表现，不能替代画质判断，也不能称为 GPU 耗时。

后续钢琴与汽车按相同规则分别固定整机、材质近景和动作状态，但使用各自镜头与阶段配置。不同商品的全景像素不能直接计算为共同画质分数。

## 已有证据的适用范围

- `9444790` 旧版与当前版可展示整体升级；最新相机距离为旧版的 0.88，布景也改变，不能据此量化某一种反射算法的提升。
- `seamless-initial` 与 `seamless-final` 为同一镜头下将反射环境底光收至 0.35 的较窄对照，不是 WebGL/WebGPU/路径追踪对照。
- 真实反射目标像素变化、复原摘要一致、资源释放检查证明功能与确定性，不证明照片级真实性。概念图是美术方向，不是同资产、同镜头的物理真值。
- B0 冻结时尚无跨渲染方案对照、离线物理参考或本轮帧时间/显存测量。10 月 12 日另完成三后端共同输入的 15 图与两张 1024 样本路径参考；实验不含生产专属特效，也不等同离线物理真值或生产帧率/显存峰值测量。用户主观质量验收仍待反馈。

B0 冻结阶段只整理、校验证据，没有改变材质、相机、光照、资源、数据库、API 或生产监测。之后的精修和管线比较为独立功能节点，详见本文开头链接；原 B0 场景验证见 [天空盒验收](typewriter-skybox-validation.md)。
