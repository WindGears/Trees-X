# 管理端操作说明

入口：http://127.0.0.1:5181/admin。默认本地演示账号admin，密码123456；初始化及环境覆盖说明见server/README.md。本说明对应2026-10-08管理易用性D2。

## 完成一次配置任务

1. 登录，在商品列表点“编辑”。新建时先选择已有商品作为配置起点，再填写新名称与唯一slug；新商品默认下架。
2. 在分区表单修改信息。切换分区保留输入，页面显示未保存状态。新增条目填写必需字段后才可保存或预览。
3. 点“预览当前配置”。预览使用未保存草稿，后端只做校验，不写数据库；返回编辑保留输入。
4. 如需改镜头，在预览中左键旋转、滚轮缩放、右键平移，选择回填目标，点“使用此取景并返回”。表单提示“尚未保存”。
5. 点“保存修改”。成功后以服务端配置与并发版本为新基线；需要时再上架。前台重新加载后读取新内容。

保存上架商品会直接更新可读取配置，没有独立发布快照；已打开的访客场景保持原加载配置，重载后更新。预览和镜头回填都不能代替保存。

## 分区与可编辑内容

| 分区     | 操作及注意事项                                                                                                             |
| -------- | -------------------------------------------------------------------------------------------------------------------------- |
| 基本信息 | 名称、分类、介绍、封面同源路径、排序、资产状态。封面显示预览或加载失败提示；流程样板/正式展品与上下架是两种状态。          |
| 部件热点 | 新增、复制、删除、上下移动；名称、说明、绑定节点。展开坐标可改聚焦偏移与可选局部锚点；节点名区分大小写，须在真实预览核对。 |
| 外观     | 名称、颜色选择器、六位十六进制；新增/复制/排序/删除。第一项为默认外观，至少保留一项。外观材质绑定仍在高级配置。            |
| 镜头     | 默认取景、缩放范围及预设视角；折叠坐标或进入预览采集。perspective是必需全景，不能删除。                                    |
| 动作     | 已有动作名称；v3进度动作的完整时长、展开/合拢文字。动作类型、绑定节点、行为参数和轨道在高级配置维护。                      |
| 导览     | 新增/复制/删除/排序，标题/说明，通过下拉引用视角/部件/动作，结构状态及v3停留进度。停留进度输入0—100%，配置保存为0—1。      |
| 高级配置 | 完整v1/v2/v3 JSON：模型来源、材质、轨道、舞台等。编辑后必须显式应用，不自动升级版本。                                      |

条目标识自动生成，普通表单中不随名称修改。复制保留全部原配置字段但获得新ID；排序不改变ID。被导览引用的热点/视角会显示引用步骤，先解除引用再删除。动作/结构等高级引用由完整前后端验证器检查。

导览的“此步返回全景”会合拢并恢复全景镜头，其他执行项在该步骤不参与，但原内容仍保留；取消勾选可继续维护组合配置。同时指定视角和热点时最终聚焦部件，v3停留进度在动作指令之后生效。

## 使用高级JSON

表单修改自动反映到尚未编辑的JSON。手动修改JSON后，内容只进入独立缓冲；点“应用到表单”通过完整校验才替换草稿。无效文本不会覆盖原表单，且阻止保存和预览。

离开未应用的JSON会询问是否放弃：取消保持当前文本，确认只丢弃JSON缓冲，已有表单修改仍保留。也可直接点“放弃JSON输入”。应用成功只更新本地草稿，仍要手动保存。未修改的资源、材质、舞台、动作轨道和可选配置保持，不自动将v1/v2升级为v3。

## 采集真实取景

可从镜头分区的“为默认取景采集镜头”或各预设的“为此视角采集镜头”进入；预览内仍可重新选择回填目标。

- 默认取景：同时更新camera.position/target与perspective视角，保证初始和复位镜头一致。
- 其他预设：仅更新该条目的position/target，默认镜头不改。
- 缩放范围保持原值；配色、动作、开门和分层状态均不回填。

采集前退出导览，暂停相机与动作补间，再读实际相机位置和观察目标。加载、错误、页面隐藏及上下文丢失时禁用采集；恢复首帧就绪后才能采集。返回编辑卸载场景，没有持续相机坐标同步。右键平移只在管理预览启用，访客仍左键旋转/滚轮缩放。

## 错误与输入保护

字段错误显示在输入下方，顶部摘要可点击跳到分区及字段。数字字段可以暂时清空；空值不会写成零，补完整前不能提交。无效颜色、重复标识、失效引用与完整配置错误均阻止保存/预览。

请求期间禁用编辑，不自动保存。保存失败或并发冲突保留输入；冲突后可核对高级JSON备份需要的修改，再明确确认“重新读取”，不要把重新读取当作自动合并。重新读取、返回列表、切换模块、主动退出或关闭页面时会提示未保存内容。

收到会话失效通知后关闭预览，保留草稿并要求重新登录；重新登录后继续编辑/保存。草稿只保存在当前页面内存，刷新页面或主动确认离开会丢失，不能当作持久化草稿版本。
