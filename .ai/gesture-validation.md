# 单商品手势原型验证

日期：2026-09-14。目标：Windows 桌面 Edge。此轮范围是手势原型，不代表后续阶段完成。

## 自动化

- `npm run check`：类型、lint、格式、Vue 行数、模型预算及 18 项单元测试。手势用例覆盖镜像相对旋转、失踪与突变重置、捏合持续时间和单次释放、目标中途离开、鼠标接管、权限拒绝、迟到摄像头、迟到视频位图、单帧在途及后台清理。
- `npm run test:browser`：本机 Edge，1440、390、320 宽度；真实 GLB、单 Canvas、视角和缩放像素变化、失败重试、上下文丢失恢复、WebGL 降级、减弱动态与键盘入口。
- `npm run test:gesture`：本机 Edge 模拟摄像头。真实 MediaPipe Worker 加载并处理空白帧；验证默认不加载识别资源、开启/关闭、模式切换、部件说明、鼠标接管/恢复、移动端无横向溢出、请求全部同源。未采集物理摄像头。

浏览器脚本可用 `CHECK_URL` 指定服务。手势脚本默认 5180，基础回归默认 5178。截图与 JSON 在 `.impeccable/review/`。

`npm run build` 已通过，手势浏览器流程也在 5181 的生产预览运行通过。窗口宽度切换后的可见性恢复纳入回归；修复了 IntersectionObserver 同批多条记录只读取第一条而残留暂停状态的问题。构建仍有场景分包体积提示：约 972 kB（gzip 266 kB），未通过提高告警阈值隐藏。

## 真人验收待做

1. Edge 打开本地页面，开启手势，允许摄像头。确认预览镜像自然、关闭后摄像头指示灯熄灭。
2. 张掌左右移动、移出再入镜；观察方向、抖动与是否跳转。
3. 正面视角后恢复手势，选择模式下尝试 20 次捏合确认；记录成功次数、误触次数及光照条件，不预填成绩。
4. 连续体验 3 分钟，记录手臂疲劳、识别中断、拖动响应和设备型号。推理耗时显示只代表最近一帧，不等于端到端延迟或帧率。
5. 测试拒绝权限、摄像头被占用、切到后台、鼠标接管与恢复。

## 限制

CPU 推理上限 15 Hz，实际频率取决于推理速度。资源初次下载较大：模型约 7.8 MB，浏览器会选择一个约 11 MB 的 WASM 变体；本地缓存之后可复用。未测低端机器、实体移动设备、Safari 或长时间内存曲线。热点遮挡按原音箱正面定义，后续更换模型需重新校准。
