# Reventón 本地离线演示：当前前置结论

更新于 2026-09-25。此文替代 2026-09-23「必须先装 VRED、VPB 尚未解码」的旧结论。

## 用户确认的范围

使用 `lamborghini-reventon-re-made-1.snapshot.2/` 的模型，通过 Blender 制作固定镜头的离线演示，目标纹理、光影与原成片一致。该演示最终前台只提供播放、暂停、章节和重播，不提供自由相机。用户明确要求：达不到目标不要硬做，缺条件要明确告知。用户没有其他 textures/maps 文件夹。

## 已完成的恢复

- `CR1.3dm` 为 44,562,088 bytes，共 609 个源对象；607 个 Mesh 与 2 个 Brep 的 11 个缓存面完整导入，共 618 网格、733,374 顶点、1,027,841 三角形。没有减面，全部具有 UV 与法线。原场景中的开门/开盖变体保留但隐藏。
- `2 TEMP.vpb` 为 378,074,196 bytes，已只读解码 730 个 DEFLATE 块，得到 764,929,436 bytes 的 OpenSG 数据。没有执行源文件内脚本。
- 已恢复 256 个 Image 记录、186 份唯一像素数据，其中包含缩略图，不能宣称有 186 张生产贴图。此前判断缺失的胎侧法线、车标和细节图可从 VPB 内嵌数据恢复；不再以原外部路径不存在为由判定资源缺失。
- 原摄影棚半浮点 HDR 已恢复；转换成 2048×1024 线性经纬图。环境旋转及额外面光属于 Blender 重建，不宣称原光照已经完整迁移。
- 材质参数、21 组保存相机及相关色调参数已提取。材质参数提取不等于 VRED 着色模型、投影和节点关联已完整移植。
- 整车对应 **6-beauty.jpg**，轮圈对应 **7-beauty.jpg**；旧文的 7/9 对应关系错误，9 是内饰。
- 原 JPG 元数据显示 Photoshop CC 2015 保存记录；文件夹没有 PSD，未知其最终调色过程。

## Blender 可用性与产物

Blender 5.2.2 LTS 与 RTX 5060 Laptop GPU 的 Cycles / OptiX 已实测成功。当前无需为了运行流程再安装其他创作软件。rhino3dm 只作为工作区局部转换依赖，不要求安装 Rhino。

当前工程为 `artifacts/reventon/reventon-restored.blend`。纹理已打包，可在 Blender 内继续修改。独立后台构建脚本不覆盖用户前台场景；切换前台文件前另存了工作状态副本 `live-checkpoint-20260925-102659.blend`。

已输出两张 3968×1758、16-bit PNG 检查图及线性 EXR 母版。对照页为 `artifacts/reventon/comparison.html`，使用原 JPG 与真实新渲染，不以参考图片替代三维渲染。具体校验、耗时与视觉差距见 [静帧验收记录](reventon-validation.md)。

## 当前阶段门槛

1. **资产/场景完整性已通过；最终视觉还原未通过。** 车灯与风挡高光、车漆层次、背景梯度、轮胎法线和碳纤维表现仍需调整。
2. 先在现有 Blender 场景中校准材质、投影、灯光和色彩；继续以整车/轮圈两张原比例静帧比较。不能通过加粒子、剪辑或快速切镜掩盖静帧差距。
3. 静帧达到要求后才制作场景内固定镜头运动与分段离线渲染。保持高精度帧母版，再编码网页播放素材。
4. 前台播放器及取消该演示自由操纵尚未实现；原七商品前台本轮没有修改。

若坚持恢复原 VRED 着色计算而非继续在 Cycles 重建，VRED 可作为直接读取原材质关系的后续工具选项，但当前没有验证它能自动复现 Photoshop 最终成片，不保证安装即解决问题。
