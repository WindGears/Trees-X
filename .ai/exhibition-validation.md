# Trees X 桌面展厅优化验收 · 2026-09-21

## 交付范围

按顺序完成了商品切换可靠性、默认沉浸布局与三件主展品、导览与手势首次体验三阶段。本记录说明工程与自动化结果，不代表真人测试或美术终审。

## 阶段 1：商品与真实画面一致

根因：Tres 5.8.3 在 always → manual → always 后，绘制帧预算可能保持为零。新模型已经进入 scene，但仍显示旧画布。现将 Canvas 固定为 on-demand，SceneRenderDriver 在电影画质主动请求连续帧，暂停/恢复仍使用同一 renderer。

选择代次贯穿模型状态、错误、热点和视觉就绪事件；每个模型实例持有固定商品配置。旧实例只能释放自己持有的资源和桥接回调。新模型挂载且完成一次实际 render 后开放操作。加载遮罩显示新商品封面；错误可重试或返回目录。

生产预览的绿植 → 目录 → 手柄路径同时验证真实 mesh 名、WebGL draw 调用增长及切换后截图；直接打开手柄与切换后得到相同网格清单，未残留植物。普通切换与画质切换 Canvas 身份不变。仅上下文丢失恢复允许重建失效 Canvas。

## 阶段 2：默认沉浸浏览

首屏默认音箱，已有 product 深链接继续生效。中文名称优先，左侧一行介绍与辅助编号；底部外观、细节、结构、手势；右侧一次一个面板。顶部完整控制台保留。面板关闭保留配色、结构、镜头和会话。滚轮缩放与侧栏滚动分别工作；返回全景恢复完整外观但保留配色。

音箱使用银色反射、石墨背景；赛车使用暖色强调、深色展台和阴影；植物使用灰绿背景、自然侧光且没有发光环。每件有独立镜头、目标与缩放范围。手柄镜头围绕真实手柄观察点，减少线缆主导。

七件目录封面均为本站真实 GLB 渲染，960×600；三件精选优先。文件大小、SHA-256、真实网格名与许可见 `public/covers/exhibition`。

## 阶段 3：探索与手势

三件主展品均有三步导览，步骤关联真实热点或结构状态。植物的最后一步观察盆内石子，不虚构内部拆解。退出保留观察状态，自由操作退出步骤控制。

手势先显示可跳过示范，显式点击才请求摄像头。镜像预览与取景框默认可见，诊断折叠；默认悬停确认，捏合在进阶选项。保留 One Euro、目标捕获、校准、有限惯性与鼠标优先。关闭面板不停止同一个 MediaStream；顶部提供摄像头状态与关闭入口。

## 工程与浏览器证据

- `npm run check`：TypeScript、ESLint、格式、架构检查、模型预算通过；65 个测试，18 个测试文件；55 个 Vue 组件均不超过 300 行。
- `npm run build`：通过。Three 场景 chunk 仍有体积提示，桌面画质保持用户指定值。
- `test:identity`：绿植→手柄、真实网格、draw 调用恢复、同 Canvas，通过。
- `test:render-handoff`：剔除 DOM 叠层后，镜头、模型、材质真实像素改变，三次画质往返，通过。
- `test:browser`：桌面、390/320、键盘跳转、错误重试、WebGL 降级、上下文丢失恢复，通过。
- `test:collection`：七件导航、搜索/分类、连续选择、后退、深链接、试色、聚焦、结构、导览、目录暂停恢复，通过。
- `test:experience`：桌面/兼容窄屏的材质与结构真实像素、焦点、缩放、导览、复位和输入接管，通过。
- `test:gesture`：真实本地 Worker + 合成摄像头、资源按需、启动/关闭、隐藏面板保持流、鼠标接管/恢复，通过。
- `test:gesture-interaction`、`test:gesture-motion`、`test:gesture-dwell`：合成关键点下的捏合、校准、惯性、丢失、悬停、静止不重复确认、商品切换及所有权，通过。
- `test:visual`：自动演出一次、重播、中断、HDR、单 Composer、1600 粒子、真实像素差异及降级，通过。
- `test:exhibition`：默认关闭侧栏、单面板、关闭保留状态、返回全景保留颜色、滚轮、拖动退出导览，及三件主展品 × 三种桌面尺寸，通过。

原始日志与运行退出码：`.impeccable/review/exhibition-validation/`。悬停旧脚本的逐字节 PNG 相等断言因透明 Canvas 合成舍入误差失效；改为排除 DOM 后，沿用已有的严格像素容差（至多 4 像素、通道变化至多 1），不是放宽摄像头或相机的行为断言。

本机 Edge headless 在1440×1000、10秒间歇命名视角交互中采集1798个 rAF 间隔，中位5.6ms、P95 5.7ms；详见 `.impeccable/review/phase-4-visual-report.json`。这是当前机器的浏览器帧间隔证据，不是 GPU 耗时、真人操作或跨设备承诺。桌面参数未随结果降低。

## 截图与集中修正

`.impeccable/review/exhibition/` 保存音箱、赛车、植物在1280×720、1440×1000、1920×1080的全景、细节与展开面板，以及目录、390/320兼容截图。首轮后集中修正手柄封面引用、手柄观察点、普通边桌取景和移动截图的过渡等待。未进行无限轮次的视觉微调。

## 待真人验收

没有人在摄像头前完成这轮测试。首次成功时间、确认成功次数、误触、手出画后的感受与重新接回表现全部待测，不能把合成输入结果填入这些指标。

建议在答辩设备上，正常室内光线下各做5次：单手识别→左右旋转→悬停确认；再做左右出画与重新入镜，分别记录误触和恢复时间。捏合留作进阶对照。后台、AI讲解、多人空间、截图分享按原计划保留到后续。
