# 历史参考：打字机静止精修验收

2026-10-12 的静止精修交接记录。当前用户目标已调整为操作中持续保持高质量，最新入口见 [打字机实时验收](typewriter-realtime-handoff.md)。本页保留旧实验的检查方式与边界，不作为当前默认渲染方案；本人验收仍待反馈。

## 打开方式

先运行 `npm run demo:start`，打开：

`http://127.0.0.1:5181/?product=typewriter-study&renderPipeline=hybrid`

已准备的本机使用生产构建，前端 5181、Spring Boot 8089。重新构建时先 `demo:stop`，再 `demo:prepare` 和 `demo:start`。`?renderPipeline=webgl` 保留原增强 WebGL 对照，普通首页仍使用原入口。

混合入口需要支持 WebGPU 的桌面浏览器；页面状态必须显示实际后端，不能把兼容 WebGL 当作新管线验收。首次着色器／追踪准备较慢，当前一次本机记录首精细图约 44 秒；首个真实光栅帧就能操作，不需要等待。

## 建议检查顺序

1. **整体与自由观察**：旋转、滚轮和命名视角应立即响应；松手静止后观察“画面精修中”到“精细展示”的变化。重复移动，旧图不能盖回新姿态。
2. **关键近景**：在细节面板观察字键金属边缘、字符贴片与键帽及后罩漆面，分别等完整精细结果。检查文字、反射、细边和阴影，不仅看整体变亮。
3. **动作与结构**：演示 A 键联动、分层、任意暂停、反向合拢、全部平铺与复原。在中间状态自由观察并点击部件，细引线标签与聚焦应跟随真实部件；观察输入暂停商品动作，返回后不自动续播。
4. **继续精修**：从已有精细图点击“继续精修”，画面应显示正在累积的原图，有噪声是此模式的正常区别。保持姿态可累积到实际 1024 样本；等待中拖动／滚轮，立即取消并恢复实时观察。
5. **界面与恢复**：关闭面板不重置状态；“复位视角”只改镜头，“返回全景”合拢且保留外观，“还原商品”恢复完整默认状态。“仅实时展示”停止精修，关闭后可再次计算。管理未保存预览与取景回填沿用原规则。

## 已完成与边界

312 单元测试／61 文件、48 交付工具测试和构建通过；五取景共同输入 32／64／128 引导图与 1024 原图、生产五取景、原图续算及输入接管、权重失败重试和实际 GPU 设备恢复通过。连续五次精修后的程序／纹理／几何／渲染目标计数保持固定。完整证据与计数含义见 [混合管线验收](hybrid-pipeline-validation.md)。

这版保留真实 Three.js 几何、实例、拾取与自由相机，不是影片或图片序列。精修提升当前资产的光照、反射与阴影，不会补造缺 UV 材质纹理或提高源字符图的分辨率；仍为机构演绎，不宣称工厂机械精度。钢琴／汽车迁移及混合管线 30 次切换／20 分钟联合验收未执行，本人画质和体验反馈也不由自动化代替。

反馈时记录：所在视角或结构状态、操作顺序、是否已到“精细展示”，以及具体异常。实际阻断问题修复后再考虑默认切换与另外两件商品。
