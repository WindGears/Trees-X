# 汽车启动与场景帧率短测

日期：2026-10-21。生产代码基线 `e6c811e`，本批不改材质、贴图、几何、光照、渲染参数、API或数据库。

用户最终限定本轮只看启动加载和运行帧数，停止重载／长时间验收。已停止仅属本测试的 Node 进程，未终止用户浏览器。未完成的重载材料只保留在忽略目录，不算联合验收通过。

## 入口与方法

实际输出1440×1000，Edge155、NVIDIA／Blackwell，真实API／GLB／runtime-v2摘要校验，WebGPU＋SSR＋DDGI＋既有过滤，唯一Canvas与renderer。入口：

`/?product=reventon&renderPipeline=realtime&indirectLighting=ddgi&assetLoading=streaming&reventonAsset=runtime-v2`

五组加载使用独立浏览器profile：每组cold先清HTTP缓存，随后同URL正常reload为hot。没有清OS文件缓存或驱动缓存。时间是导航起点至真实首帧后DOM可操作状态、以及请求的DDGI就绪观测，不是独立GPU耗时。

## 启动结果

| 指标           | cold五次中位 | hot五次中位 |
| -------------- | -----------: | ----------: |
| 完整材质可操作 |     19.910秒 |    20.240秒 |
| DDGI就绪观测   |     22.677秒 |    22.935秒 |

cold可操作范围19.748—21.428秒，hot范围19.612—20.506秒。十次均通过实际模型、≤4K纹理、DDGI、唯一Canvas及同源请求检查，无意外错误。cold模型HTTP编码传输约451.7MiB；hot每次观察到150个真实304，编码传输约96.4MiB（含协议开销），没有把hot直接当作全部命中缓存。

冷样本一的合并资源／解析阶段约0.709—12.284秒，材质阶段约12.284—12.484秒，首帧准备至真实就绪约12.484—21.412秒。资源请求、解码、转码和解析有重叠；不能将约11.6秒都叫下载，也不能把约8.9秒都叫GPU绘制。热传输明显减少而启动时间接近，说明只缩下载体积不足以解决当前启动延迟；后续应分别测解析／转码和预编译／上传／首帧准备。

## 普通运行短测

`scripts/reventon-startup-fps-check.mjs`使用真实协调器的完整帧计数：仅在完整场景绘制提交及运动／历史commit后增长。按同一页面单调时钟计算增量／秒；没有GPU查询、Trace、额外绘制、RAF或画质变化。显式激活已知本机测试tab，记录真实focus／visibility，预热5秒，每段约10秒。

| 操作         | 完整帧数 | 实际时长 | 场景提交帧率 |
| ------------ | -------: | -------: | -----------: |
| 鼠标绕行     |     1310 | 10.045秒 |   130.4帧/秒 |
| 双门往复     |      965 | 10.047秒 |    96.1帧/秒 |
| 部件分离往复 |      967 | 10.019秒 |    96.5帧/秒 |

三段focus持续为true，DDGI实际启用，无浏览器错误／请求失败，单宿主，测试浏览器清理完成。本次额外加载为20.103秒可操作、20.838秒DDGI观测，仅单样本，不替代五组中位数。

**上述是场景提交吞吐，不是显示器实际呈现FPS，不据此认证P95显示间隔或稳定30FPS。** 第一版短测未显式激活tab，虽document.hasFocus为true，却只记录到约1帧/秒；加入与既有交互测试相同的`page.bringToFront()`后恢复上述吞吐。保留两份记录，说明测量受页面激活／窗口呈现条件影响；未据此证明唯一操作系统根因，也未用该1FPS推导显卡负载。应在访客实际前台操作中复核这一条件，不能默默删去异常。

## 先前带采集对照及限制

同日三轮各30秒有窗口测量已完成绕行、开门、分离的实际覆盖。JS提交回调中位7.2—10.1ms、P95约10—18ms；GPU timestamp有独立render／compute结果，不能相加各pass的中位数冒充整帧。compute组中位7.537ms／P959.961ms，不代表每帧固定追加该成本。

该批Trace超过既有128MiB读取预算，已关闭流，未形成有效呈现证据。没有把RAF／Swap／提交回调替代显示呈现。桌面窗口工具因不能确认URL被自动审查停止；未继续该类操作，后续仅使用可确认本机URL的项目浏览器脚本。

短测首次尝试的GPUAdapterInfo.toJSON不存在错误属于工具问题，已改为读取公开字段后重跑；失败报告保留，不当成汽车故障。开始时服务已停止，`demo:doctor`核对产物／资源后经`demo:start`实际启动；没有将服务未开时的fetch失败计入加载秒数。Cline只读审查两次未形成完整结果（轮次预算／长度截断），未应用输出；测试与数据由主代理核对。
