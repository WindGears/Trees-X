# 打字机材质、接触阴影与结构路径精修

2026-10-12（10-11 开始）。本轮按用户要求，精修现有真实打字机的漆面、金属与接触阴影，并核查整体、近景和分层/平铺的穿插。保留唯一工作台、原资产与当前摄影棚，不用影片或预渲染序列。生产场景实机检查、生产构建确认及独立同输入渲染比较均已完成；CPU 测试不能代替画质检查。

## 固定基线与范围

B0 为 `d5f46f28b5ce5491cfcdb424fbe19a5caa0dd39c` 的打字机实机版本，七张既有生产截图、通过报告与完整展示配置冻结在本机忽略目录 `artifacts/visual-quality/B0-typewriter-20261011/`。根代理已核验七图及原提交源码摘要，规范与元数据见 [画质基准](visual-quality-baseline.md)。历史报告未逐图记录实际 target、zoom、viewOffset 或全部可变材质值；源码推导字段仍保留来源标注，不能把 B0 说成完整的自动化控制变量实验。

本轮不修改源 GLB、原贴图、模型节点轴心、默认相机、舞台布局、API、配置版本或数据库。源几何与初始/最终平铺端点保留；有几何证据的分层与平铺中间路径已经修正，不再使用“分层和平铺完全未改变”的描述。

## 标准材质微表面

实现为 `typewriterFinishes.ts` 与 `typewriterMicroMaps.ts`。早期漆面/金属的 onBeforeCompile 程序噪纹已撤除；不使用底色斑块制造材质感。复用 loader 创建的 Standard/Physical 材质和原身份，保留源底色、贴花、用户试色及已有贴图，不替换或复制源材质。

| 范围                                  | 当前处理                                                                                  |
| ------------------------------------- | ----------------------------------------------------------------------------------------- |
| enamel                                | 粗糙度 0.26、清漆 0.76、清漆粗糙度 0.15、漆面金属度 0.035；含缺 UV 表面，不添加微表面贴图 |
| shellGloss / shellRim                 | 保留清漆层，标准法线/粗糙度微表面；法线权重 0.055，shellGloss 为 0.23/0.8/0.14            |
| chrome / edge / goldEdge / goldChrome | 源金属度与色彩保留；克制的 UV 各向异性、长向微细法线与粗糙度变化，法线权重 0.09           |
| iron                                  | 各向同性微表面、原较高粗糙度，法线权重 0.035                                              |
| steel                                 | 含缺 UV 表面，保留干净标准参数，不添加贴图或各向异性                                      |
| 贴花、键帽、丝带、橡胶                | 不纳入此次材质安装；透明、深度状态与回调保留                                              |

真实 GLB 检查：enamel 的 11 个 primitive 中 6 个无 UV，steel 的 82 个 primitive 中 2 个无 UV；本轮添加贴图的材质均有完整 UV。后挡板 part-095 主体属于缺 UV 的 enamel，不宣称其已完成完整微表面贴图制作。若实机比较证明仍不足，再通过明确的 Blender 制作母版整理 UV，不在运行时偷偷投影或修改源 UV。

微表面为三类确定性 128² RGBA DataTexture，各含 normal/roughness 两张图；使用线性数据色彩、RepeatWrapping、双线性与 mipmap，粗糙度读取绿色通道。纹理在准备时一次生成，不依赖逐帧随机数；金属条纹变化主要沿一个方向，微法线和粗糙度幅度保持轻微，不将漆面变成皮革或所有金属变成镜面。这些参数属于演示材质，不作真实制造工艺声明。

同一模型的类别共享生成图；重复 apply 不创建新图或增加材质版本。新增图不交给加载前建立的源资源收集器，而由材质 dispose 监听递减引用，最后一个使用者唯一释放两张图，并移除监听/绑定。loader 继续唯一释放原 geometry/material/texture；测试覆盖源 owner 与生成图共存及重复清理。

标准贴图便于跨 renderer 复用，但不能自动保证所有渲染器的 BRDF 特性相同。本轮比较采用 three-gpu-pathtracer 的 WebGPU 分支；其材质 BRDF、环境过滤及纹理采样与光栅存在差异，具体输入与边界见 [渲染比较](render-pipeline-comparison.md)。

## 接触阴影

`studio/contactShadow.ts` 保留当前姿态深度投影、两次连续模糊和 dirty 驱动刷新。两张 1024² 目标改为 HalfFloat，减少微弱半影在多次采样中的量化；收紧高斯模糊，减轻高处部件阴影与整体叠加强度。接收面尺寸现在与正交投影一致，避免旧接收面收缩导致脚位/离中心部件阴影缩放错位。地台、相机与工作台照明布局不变。

继续排除透明/透射源表面，保存并恢复 renderer 的目标、视口、剪裁、XR、背景、overrideMaterial 及阴影状态。失败保留 dirty 以便重试；卸载移除接收面、恢复源层标志并唯一释放离屏目标和辅助资源，不释放源模型。

这是姿态相关的接触阴影近似，不是全局光照，也不等于任意距离下的物理半影或内部自遮蔽。HalfFloat 能力沿用现有反射舞台依赖；已检查整机、近景与结构截图，不由目标尺寸或格式推算帧率，本轮未提供生产帧率排名。

## 结构与穿插修正

`typewriterRig.ts` 继续从基准姿态按归一化进度确定性计算，GSAP 只补间进度/击发量；相机、热点、试色与动画状态职责不变。

- 有限击发维持 0.35 rad，保留键帽下压和键杠杆转动，支持 41 条完整按键/杠杆/字杆绑定；44 条字杆不等于 44 条均具备击发绑定。
- 分层对 part-095 后挡板与 part-097 前罩的 Z 路径增加避让，消除原盖板与滚筒、桥罩和字杆扇相关的指定穿插。
- 平铺对十个大件错开横移、转向和下降区间，返程杠杆先退出轨道，前罩先让出字杆旋转空间。原 572 部件的初始与平铺终态保持，不累计变换、不进行运行时碰撞求解。

CPU 证据采用实际 GLB 顶点/三角面及 MeshBVH，而非仅检查包围盒：

- A 字杆对移动滚筒：101 个结构进度 × 21 个击发行程，指定三角面没有采样交叉；最小橡胶径向净距为 +0.117652799 源单位。旧 1.15 rad 击发设为正例，测试能检出原交叉。
- 两盖板相关三对部件：在脱离后的结构进度 0.05—0.6 与 21 个击发行程检查，修正后无采样交叉；恢复原展开位置能复现原问题。
- 平铺：44 字杆与 11 个大件间、以及大件相互之间共 539 对，结构进度 0.6—1 抽样 401 点，修正后无检测交叉。这里十个大件修改路径，11 个大件参加检查，不能混用数量。
- 保留实际源 572 部件初始局部姿态与平铺端点（位置误差 <1e-11），旧确定性/重复复原与键帽/杠杆联动检查继续存在。

以上覆盖指定部件和离散采样，不包含全部小零件组合、连续扫掠体或工厂机械接触认证；合拢面板原有装配接缝也不被直接判为拆解失败。不能写成“整个模型所有状态绝对无穿模”。
