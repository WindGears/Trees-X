# R18 首帧阴影准备

## 启动耗时分解

使用已启用原生管线预编译的 1440×1000 生产预览做阶段追踪。两次原路径样本中，模型读取、解析和纹理准备为 5.34–5.48 秒，摄影棚准备为 1.89–2.31 秒。间接光纹理读取为 0.44–0.88 秒，首次探针构建为 1.14–1.27 秒。阴影 Worker 约 2.54–2.59 秒，与间接光重叠，实际等候 Worker 约 0.41–0.94 秒。

显式准备阴影纹理目标约 4.59–5.14 秒。细分追踪中，原始可见性目标的一次 `compileAsync` 花费 4.97 秒，并触发其表面输入的准备和绘制。同次阴影队列等待不足 1 毫秒。首次完整绘制本身为 6.46–6.80 秒。[Three r185 RTT 源码](https://github.com/mrdoob/three.js/blob/r185/src/nodes/utils/RTTNode.js)

## 首帧准备流程

R18 在当前 GPUDevice 已完成对应管线的预编译时，直接在实际首帧初始化阴影目标。原生灯光绑定、完整尺寸、两条面积光射线、历史长度、DDGI、4K 材质和绘制后的提交判定沿用既有实现。管线缓存缺失、损坏或尚未编译完成时沿用显式准备。首次发布和设备恢复均由现有工作台负责。

运行 `npm run asset:reventon-native-pipelines` 时，采集脚本要求当前构建实际走完首帧阴影、原生 WebGPU 与 DDGI。登记和内容摘要覆盖这条绘制顺序。升级时先启动包含此实现的构建，再生成本机缓存和重建演示包。`TREES_R18_PSO_REFERENCE=1` 可采集原显式准备版本。`&r18ShadowWarmup=reference` 可在同构建检查显式准备行为。

## 交叉实验

沿用旧管线缓存直接初始化时，界面就绪提前，首帧另有 125 份首次出现的 WGSL，整页 GPU 结算仍为 23.69、25.36 秒。重新采集对应的 123 种管线后，两轮各匹配首帧 128 次创建请求中的 124 次。

| 同构建交叉对照 | 界面就绪 | GPU 队列结算 |
| -------------- | -------- | ------------ |
| 显式准备 A     | 21.48 秒 | 21.61 秒     |
| 首帧准备 A     | 17.62 秒 | 17.74 秒     |
| 首帧准备 B     | 18.67 秒 | 18.79 秒     |
| 显式准备 B     | 20.41 秒 | 20.57 秒     |

两种绘制顺序均读回了实际 1440×1000 RGBA16F 的原始与过滤可见性。闭门和开门各有实际遮挡、半遮挡与受光像素，全部数值有限且在 `[0,1]` 内。测量描述对应机位的输出，随机采样与历史推进仍会带来帧间差异。

原始阶段追踪和独立试验位于 `artifacts/r18-startup-deep/lighting-study-*`、`shadow-rtt-study-*` 和 `shadow-firstframe-pso-*`。

## 构建检查

正式构建生成 123 种管线，压缩缓存为 950,244 字节。两次新无头浏览器冷启动的界面就绪为 17.99、17.70 秒，GPU 队列结算为 18.16、17.82 秒。完整画面均核对了 4K BC7、DDGI、软箱阴影和唯一 Canvas。

与上一版的相同取景相比，8 位 RGB 车身采样区平均绝对差在全景为 0.195、双门打开为 0.309。地面采样区小于 0.0002，灯板采样区一致。缓存损坏和缺失时均选中原预热流程，真实 WebGPU 首帧及软箱阴影通过。

正式构建、阴影读回、视觉和回退证据为 `shadow-firstframe-package-*`、`shadow-firstframe-visual-*` 和 `shadow-firstframe-fallback-*`。

三件展品和同宿主切换通过，联合检查中汽车 GPU 队列于 18.60 秒结算。管理预览、取景回填和真实设备丢失恢复四项通过，检查中保存的汽车光照快照均走首帧阴影。延迟缓存请求期间切换展品，取消了旧请求并在原 Canvas 与 renderer 中成功返回汽车。报告为 `shadow-firstframe-showcase/report.json`、`shadow-firstframe-admin/report.json` 和 `shadow-firstframe-cancel.json`。

类型检查、ESLint、生产构建、架构、模型、1010 项单测及相关工具测试通过。全库 `npm run check` 在已有的 `PERFORMANCE_OPTIMIZATION.md` 格式项停止，其余步骤单独运行。

5181 演示包重建后，新无头浏览器两次界面就绪为 19.12、18.51 秒，GPU 队列结算为 19.34、18.62 秒。两次均使用 123 种管线的本机缓存及实际首帧阴影。静止停止绘制、拖动唤醒和窗口调整验证通过。上一版同端口两次 GPU 结算为 22.75、21.81 秒。新报告为 `shadow-firstframe-release-a.json` 与 `shadow-firstframe-release-b.json`。
