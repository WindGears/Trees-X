# Trees X 桌面体验审查 · 2026-09-20

目标：src/components/product/ProductShowcase.vue；现有生产预览 http://127.0.0.1:5181/?product=potted-plant；实际检查视口 1280×720。此次审查不修改应用代码。

## 判断

现有系统有完整的三维交互能力和统一外壳，但商品辨识、内容价值和操作层级弱于舞台特效。统一蓝色光环可以套用任何物品，缺少针对材质、形态和用途设计的展示。需要把一组功能组织成「被吸引 → 看懂 → 自主探索 → 带走印象」的体验。

## 优先问题

### P0：商品切换后画面与名称不一致

复现：绿植 → 商品目录 → 复古游戏手柄。URL、标题、按钮都切到 GAME / 01，中央仍显示绿植。等待后点击正面，画面中的绿植仍在并发生视角变化。刷新同一手柄 URL 后才正确显示手柄。这是当前生产预览中的实际观察，尚未定位代码原因。下一步需要检查模型替换与场景生命周期，并把真实模型身份与 UI 一致性纳入验收，不能只验证文字更新或像素变化。

### P1：首屏缺少唯一重点

左侧巨大英文编号、中央光环、右侧完整控制台同时争夺注意力。五组功能常驻；用户在理解商品之前先面对配置工具。建议默认大幅商品与中文名称、简短介绍及「探索细节」；配色、部件、结构按当前意图展开。提供可收起控制台的纯展示状态，保留高质量视觉演出。

### P1：字号和层级反向

实际计算样式：商品中文名称 9px，英文 GAME / 01 为 70.4px；商品简介 11px，操作提示 8px，控制按钮多为 10px，手势启动 9px，来源链接反而 16px。用户难以舒适阅读。建议商品中文名成为主要识别信息，正文 14–16px，辅助说明至少 12px；编号保留为品牌装饰，不压过有意义的信息。

### P1：商品缺少专属构图与材质表现

绿植、手柄都套同一冷色光环。正确显示手柄后，线缆占据大部分画幅，握持主体很小，较亮的圆环进一步分散注意力。需要逐件确定默认镜头、视觉中心、主体占比与补光：数码突出轮廓与材质，木作突出纹理与接触阴影，植物突出叶片层次与陶盆质感。目录封面也应使用一致的艺术方向。优先打磨 2–3 件主展品，其他仍留在目录。

### P1：导览没有带来足够的商品理解

绿植导览第二步说明是「陶盆使用原始扫描贴图；试色只作用于盆体，不改变枝叶」。这是实现说明。单体手柄显示「原始资产未拆分节点」。用户需要的是看哪里、为什么值得看、材质形态有什么特点。每件主展品至少三个有意义的观察点，讲解与近景同步；尺寸、功能和工艺必须来自可靠资料，没有资料就只描述可观察特征。避免为展示结构功能把所有对象机械拆散。

## 其次补齐

- 手势：首屏入口可达，但启动前没有直观的动作演示；需要短引导、小预览和明确的识别/目标/确认反馈。首次成功后逐步开放更多动作。此次未开启摄像头，不评价真人准确率；惯性只能改善运动衔接，不能证明识别可靠。
- 鼠标操作：现有提示明确仅按钮缩放，建议加滚轮缩放、直观热点标签和统一返回全景。把直接操作作为第一条路径。
- 体验结束：增加保存当前视角截图、包含所选配色/状态的分享或记忆上次状态，让观察有可带走的结果；列为后续而非当前阻塞项。
- 完整系统：后台上传、分类与商品资料管理仍缺，但不会直接修复当前前台的阅读和商品表达问题。先把核心前台走顺，再补管理闭环。
