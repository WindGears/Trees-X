# GalleryRoot：机械探索馆候选

## 方向与范围

用户选择以展品为中心的可扩展机械探索馆：全幅展位、顶部快速切换与独立展品库。这里只记录已实现的阶段 1/2，入口 `?gallery=next`，静态原型 `?galleryPrototype=1`；不替代无参数默认入口。设计系统见 [DESIGN.md](../../DESIGN.md)，事实和验收见 [.ai/museum-validation.md](../../.ai/museum-validation.md)。

## 表面与职责

`GalleryRoot.vue` 持有目录请求、深链接、封面与异步 Viewer 生命周期。Header 提供快速切展，Library 管理搜索/分类/空态和对话框，Controls 读取真实动作会话，Inspector 按需显示观察工具。真实三维仍由既有 ExhibitionViewer 与唯一场景宿主负责；UI 不增加 renderer、Canvas 或逐帧业务状态。

默认封面不提前加载模型；展品库卡片延迟加载封面。库或帮助打开时向 Viewer 传递 suspended，关闭回到展位；目录表面不通过额外 Canvas 绘制预览。组件自有 GSAP 补间在卸载时释放，目录请求由 LatestRequest 取消；场景资源继续由原有 owner 管理。

## 构图与扩展

全幅 `100dvh`、64px 顶栏、底部居中动作条、右侧观察工具；标题为30px。检查面板 304px，1360px 以下 280px。展品库三列，1700px 起四列；4:3封面与可换行标题支撑更多展品。新展品通过公开目录与交互描述器扩展，不把数量硬编码为三件。

## 已有证据与边界

静态原型通过 1280×720、1440×1000 检查；目录隔离夹具在 1280/1440/1920 宽下覆盖 1、3、12、30 件。打字机实机报告记录真实 WebGPU、1440×1000 和三个桌面尺寸图；本次文档抽查 whole-1440 与 library-30-1440，与全幅/独立目录结构一致。不是新的浏览器验收。

移动端、钢琴/汽车/管理完整新表面、最终资源生命周期与画质仍待后续验收。历史暖夜/摄影棚和旧侧栏规范不作为本候选的默认构图。未把房间高光、模型噪点或旧全局样式覆盖写成新视觉规则。
