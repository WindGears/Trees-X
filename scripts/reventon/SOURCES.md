# Reventón 资源来源与使用边界

用户提供本地目录 `lamborghini-reventon-re-made-1.snapshot.2/`，其中为 `CR1.3dm`、`2 TEMP.vpb` 与 7 张 beauty JPG。目录没有许可文件，也没有作者授权文书；本记录不将其认定为 CC0、项目原创资产或可商业再分发素材。

本次用途是用户要求的本地恢复、静帧对照和毕业设计演示开发。输入文件保持原样；没有上传源资产，没有下载替代汽车模型或生成品牌标识。

| 资源                | 原来源 / 恢复方式                    | 当前使用                             |
| ------------------- | ------------------------------------ | ------------------------------------ |
| 车辆几何            | `CR1.3dm`；607 Mesh + 11 Brep 缓存面 | 全量导入 Blender，无减面             |
| 胎侧法线与旧化反射  | VPB Image 26050 / 26049              | 使用原 UV，Cycles 法线/反射重建      |
| 碳纤维              | VPB Image 26251                      | 原图像，尺度与材质重建               |
| 徽标字样            | VPB Image 26713、原徽标几何          | 四个轮毂原图贴片，无生成字样         |
| 外观图集 / 刹车图集 | VPB Image 27811 / 28906              | 原纹理图集                           |
| 刹车盘划痕          | VPB Image 26452                      | 粗糙度变化，环向反射为 Cycles 重建   |
| 摄影棚 HDR          | VPB Image 26515，原名 STUDIO1.exr    | 半浮点立方体转经纬环境，打包入 blend |
| 参考成片            | 6-beauty.jpg / 7-beauty.jpg          | 对照页左侧，明确标原图，不作为新渲染 |

完整导出清单包含记录 ID、原引用文件名、像素 SHA256、尺寸及文件去重映射，位于 `artifacts/reventon/textures/manifest.json`；导出文件 SHA256 与源像素逐份验证位于 `artifacts/reventon/recovery-verification.json`。当前输出文件及工程摘要位于 `renders/validation-report.json`，避免在文档内复制大量易过期的摘要。

原 JPG 元数据包含 VRED 2016 SP2 与 Photoshop CC 2015 保存信息；这只能证明制作线索，不证明拥有原作者完整后期流程。恢复原像素不等于完成原材质着色或获得新的资产许可。

后续候选也使用同一份 `2 TEMP.vpb` 的原几何、节点可见性、材质绑定、UV 和纹理投影设置。导入 2,998 个原场景可见车辆对象，无下载或生成替代零件；来源记录在 `vpb-candidate.json`。座舱对照新增 `9-beauty.jpg`；门板标识、中控和气囊字样来自原图集 28491 / 28560 / 28629，皮革与绒面来自原嵌入图像。凹凸数据的通道解码只在材质中进行，原导出像素保持不变。内饰补光和摄影棚调整属于本项目的 Cycles 重建，和原资产事实分开记录。
